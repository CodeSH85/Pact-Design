當工作區同時存在面板、下拉選單、浮動視窗與互動視窗時，使用者需要清楚知道哪些內容位於底層、哪些元素浮於上方等待處理。Pact Design 結合邊框、圓角、焦點外框與陰影深度，以低調但明確的視覺線索構築介面空間感。

---

## 邊框與圓角語言

高密度介面經常需要將多個面板緊密排列。過大的圓角容易在相鄰區塊之間產生零碎縫隙，而過粗的線條則會讓畫面顯得雜亂。

- **俐落清晰的邊框**：一般容器與分隔線以 1px 細線為主，提供明確卻不搶戲的邊界；需要強調選取狀態或鍵盤焦點時，再提升至 2px 以上的線寬。
- **收斂緊湊的圓角**：系統預設採用 3px 至 4px 的俐落小圓角，適用於按鈕、輸入框、下拉選單與卡片。緊密貼合的停駐面板與表格儲存格維持 0px 直角，微小標籤與核取方塊使用 2px 微圓角，大型浮動對話框可適度放寬至 6px 或 8px，而圓點指示器與膠囊標籤則採用完全圓角。

## 鍵盤焦點指示

清晰的焦點外框是鍵盤操作與無障礙體驗的核心。在高密度介面中，不同容器的裁切與排列方式各異，若一概採用外擴焦點，往往會被表格或捲動容器邊緣裁切。因此 Pact Design 依元件特性提供三種焦點位置策略：

| 焦點策略 | 視覺表現 | 常見使用情境 |
| :--- | :--- | :--- |
| **外擴** | 焦點外框與元件邊緣保留些微呼吸間距 | 獨立按鈕、核取方塊與卡片等周圍空間充裕的元件。 |
| **齊平** | 焦點外框緊貼元件本身邊框，不向外溢出 | 文字輸入框、下拉選單與緊湊排列的表單欄位。 |
| **內縮** | 焦點外框繪製於元素邊界內側，不被容器裁切 | 資料表儲存格、樹狀列表項目、頁籤與可捲動清單列。 |

## 陰影層級

陰影用於表達元素與底層表面之間的「海拔高度」。海拔越高，陰影的擴散範圍越寬、存在感越強，暗示該元素在互動上的優先級越高。

由於深色表面對陰影的吸收度遠高於淺色表面，Pact Design 在淺色主題採用輕盈低透明度的陰影，在深色主題則自動增強陰影深度並搭配細微邊框，確保浮動元件在兩種主題下都層次分明。

| 深度層級 | 視覺感受 | 常見使用情境 |
| :--- | :--- | :--- |
| **極淺層** | 幾乎貼近表面的微弱立體感 | 卡片微幅浮起、分段切換控制項的選中滑塊。 |
| **淺層** | 柔和但可辨識的區隔 | 懸浮操作按鈕、捲動時固定於頂部的表頭。 |
| **中層** | 明確脫離背景平面的浮動感 | 氣泡提示、小型浮動工具列與訊息通知。 |
| **深層** | 顯著高於工作區的互動覆蓋層 | 下拉選單、浮動視窗與自動完成選項清單。 |
| **極深層** | 最高優先級的全域焦點容器 | 互動視窗、側邊抽屜與指令面板。 |

---

## 畫面疊加順序

為了避免浮動元素之間互相遮擋，系統針對 Z-Index 建立了固定的堆疊順序，由底層至頂層依序為：

**基礎內容 → 停駐面板 → 下拉選單 → 固定表頭與導覽 → 側邊抽屜 → 互動視窗 → 浮動視窗 → 訊息通知**

遵循這套既定層級，能確保高優先級的系統通知永遠顯示在最上方，也不會出現下拉選單被鄰近面板遮住的異常狀況。
