在包含大量輸入框、按鈕、下拉選單與圖示的介面中，尺寸一致性是維持畫面整齊的關鍵。當同一列上的不同元件擁有相同的高度與相稱的圖示比例時，使用者就能以最少的視覺阻力掃視與操作。

---

## 控制項高度與密度等級

Pact Design 定義五個標準控制項高度，讓按鈕、文字輸入框、下拉選單與搜尋欄位在同一水平工具列或表單列中自然齊平：

| 密度等級 | 高度 | 視覺定位 | 建議搭配圖示 | 常見使用情境 |
| :--- | :--- | :--- | :--- | :--- |
| **超緊湊** | 24px | 極致資訊密度 | 12px | 資料表行內操作按鈕、樹狀節點列、密集狀態工具列。 |
| **緊湊** | 28px | 高密度工作區預設 | 16px | 側邊面板控制項、密集工具列、資料表預設列高與次要按鈕。 |
| **標準** | 32px | 桌面介面通用預設 | 16px | 一般表單輸入框、標準按鈕、下拉選單與導覽項目。 |
| **舒適** | 36px | 寬裕操作空間 | 20px | 獨立對話框內的表單欄位、需要視覺突出的主要操作按鈕。 |
| **寬大** | 40px | 焦點型操作區域 | 24px | 全域搜尋列、登入頁面表單與重點引導區塊。 |

## 圖示尺寸比例

圖示與文字、控制項之間需要保持協調的視覺重量。Pact Design 提供五個標準圖示尺寸，與各密度等級的控制項嚴格配對：

| 尺寸等級 | 尺寸 | 常見使用情境 |
| :--- | :--- | :--- |
| **極小** | 12px | 樹狀列表展開箭頭、排序方向指示、狀態標籤內的微型圖示。 |
| **小型** | 16px | 工具列圖示、選單項目、按鈕與一般表單控制項的預設圖示。 |
| **中型** | 20px | 較寬裕的導覽項目、獨立圖示按鈕與提示標題圖示。 |
| **大型** | 24px | 頂部主導覽列、區塊主標題與重點入口圖示。 |
| **特大** | 32px | 空狀態提示、功能模組引導與系統回饋插圖型圖示。 |

## 通用結構尺寸

除了互動控制項高度與圖示外，系統亦提供涵蓋 4px 至 80px 的通用結構尺寸階梯，供核取方塊、開關軌道、使用者頭像與固定比例容器使用。透過共享同一套尺寸基準，不同元件並排時能維持自然的比例關係。

---

## 尺寸應用建議

- **同列控制項保持同高**：在同一組搜尋列、篩選列或表單操作區中，按鈕、輸入框與下拉選單應採用相同的高度等級，避免視覺高低起伏。
- **依情境選擇密度**：同一產品內不必所有頁面都強迫使用單一尺寸。例如資料表與屬性面板適合採用緊湊或超緊湊等級，而設定頁或對話框表單則適合使用標準或舒適等級。
- **確保點擊舒適度**：在純圖示按鈕或緊湊控制項相鄰排列時，請保留足夠的水平間距，避免使用者誤觸相鄰功能。
