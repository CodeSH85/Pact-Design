## W3C DTCG 2025.10 結構規範

所有位於 `src/**/*.json` 的原始檔案皆嚴格遵循 **W3C Design Tokens Community Group (DTCG) Format Module 2025.10** 標準：

- **結構化型別與數值**：每個終端 Token 節點皆明確定義 `$value` 與 `$type`（且 `$value` 固定排列於 `$type` 之前）。
- **巢狀階層取代連字號鍵名**：使用 JSON 物件巢狀結構（例如 `system.background.layer-1`、`global.font.size.04`）表達分類與階層。
- **保留參照鏈 (`outputReferences: true`)**：Style Dictionary v5 編譯時會保留 `{global.*}` 與 `{system.*}` 參照關係，轉譯為原生 CSS `var(--*)` 變數鏈，實現零執行期成本的動態主題切換。

```json
// src/global/color.json
{
  "global": {
    "indigo": {
      "500": {
        "$value": {
          "colorSpace": "oklch",
          "components": [0.6, 0.192, 274.9733],
          "alpha": 1,
          "hex": "#5c64eb"
        },
        "$type": "color"
      }
    }
  }
}

// src/system/color.light.json
{
  "system": {
    "semantic": {
      "primary": {
        "$value": "{global.indigo.500}",
        "$type": "color"
      }
    }
  }
}
```

## 深淺主題雙檔案策略

Pact Design 在 **System** 層級透過分離檔案實作主題切換：

- **100% 鍵名對稱（Key Parity）**：淺色與深色設定檔具備完全一致的 JSON 路徑與 Token 名稱，絕不將 `light` 或 `dark` 字樣寫入 Token 路徑中。
- **CSS 選擇器隔離**：
  - `src/global/*.json` + `src/system/*.light.json` + `src/component/*.json` 輸出至 `:root, [data-theme="light"]`
  - `src/system/*.dark.json` 輸出至 `[data-theme="dark"]`

```css
:root, [data-theme="light"] {
  --pd-global-indigo-500: oklch(0.698 0.145 275);
  --pd-system-semantic-primary: var(--pd-global-indigo-600);
  --pd-system-on-surface-default: var(--pd-global-gray-1100);
}

[data-theme="dark"] {
  --pd-system-semantic-primary: var(--pd-global-indigo-700);
  --pd-system-on-surface-default: var(--pd-global-gray-200);
}
```

## 雙階段編譯管線

執行 `pnpm build:tokens` 與 `pnpm build:styles` 時，Token 定義與 Web 樣式層會依序編譯為兩組產物：

1. **`@pact-design/tokens`（`packages/tokens/scripts/build.ts` & `sd.config.ts`）**：
   - `build/css/_variables.css`：輸出所有 Global、System 與 Component 層級的 `--pd-*` CSS Custom Properties，並將複合型 Typography Token 自動展開為子屬性（`-font-family`、`-font-size`、`-font-weight`、`-line-height`、`-letter-spacing`）與 `font` 縮寫變數。
   - `build/meta/tokens.json`：輸出純淨的 `{ name, path, $type }` 中繼資料清單供下游工具消費。
2. **`@pact-design/styles`（`packages/styles/scripts/build.ts`）**：
   - `build/css/index.css` 與 `build/css/theme.css`：將 `@pact-design/tokens/css` 與深淺主題 `color-scheme` 規則整併為獨立分層的 `@layer pact.tokens, pact.theme;` 樣式表，讓原生捲軸與表單控制項自動跟隨 `[data-theme]` 切換。
   - `build/uno/preset.js`（`pactPreset`）：讀取 `build/meta/tokens.json` 與 `src/uno/rules.ts` 動態生成 UnoCSS / Tailwind 相容主題預設集，將 `system.*` 與 `global.*` 映射為原子化工具類別（如 `bg-layer-1`、`text-on-surface`、`text-heading-md`、`h-control-sm`、`p-md`、`rounded-xs`、`shadow-elevation-sm`），並支援選擇性啟用 `pactPreset({ preflights: true })`。
