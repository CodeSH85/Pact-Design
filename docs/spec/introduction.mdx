現代專業工具與系統管理介面往往承載大量資訊、多層次結構與高頻操作。當畫面充斥過多留白與裝飾元素時，使用者反而在反覆捲動與切換之間消耗寶貴的注意力。

**Pact Design** 是一套領域中立的設計系統，核心目標是讓複雜介面回歸清晰與高效。透過緊湊的空間節奏、精準的色彩對比與克制的互動回饋，協助設計者與開發者在有限的螢幕空間內，建立穩定、易讀且可長期維護的產品體驗。

---

## 核心特色

- **專注高資訊密度**：以精簡的元件尺寸與俐落的幾何比例，讓表格、側邊面板與多窗格工作區呈現更多關鍵資訊，同時維持清爽的視覺秩序。
- **以閱讀與效率優先**：字體排版、色彩明度與動態回饋皆以實際使用情境為出發點，屏除不必要的裝飾與干擾，讓使用者專注於任務本身。
- **跨主題的穩定對比**：淺色與深色主題同步設計，並以現代感知對比度標準檢驗文字與背景關係，確保長時間閱讀依然舒適。
- **領域中立、易於延伸**：不綁定特定產業或視覺風格，無論是分析儀表板、開發者工具或企業內部系統，都能自然融入並保持一致。
- **無障礙互動基礎**：元件內建完整的鍵盤導覽、焦點管理與語意結構，讓不同使用習慣與輔助工具的使用者都能順暢操作。

## 如何使用本文件

你可以依照角色與需求，從以下章節開始探索 Pact Design：

- **設計原則**：了解 Pact Design 面對取捨時的思考脈絡，作為團隊評估設計決策的共同基準。
- **設計基礎**：查閱色彩、字體、間距、尺寸、陰影與動態的規範，建立一致的視覺語言。
- **Design Token**：深入了解設計系統背後的分層架構、主題切換機制與前端整合方式。
- **元件**：瀏覽完整的互動元件庫，查看各元件的適用情境、互動範例與 API 參考。

## 套件組成

Pact Design 依職責劃分為三個獨立套件，方便專案按需求彈性採用：

- **`@pact-design/tokens`**：設計系統的單一資料來源，封裝色彩、字體、間距、尺寸、陰影與動態等設計決策。
- **`@pact-design/styles`**：提供開箱即用的主題樣式表與元件樣式，無須綁定特定 CSS 框架即可在各種 Web 專案中使用。
- **`@pact-design/react`**：基於無障礙互動模型封裝的 React 元件庫，提供一致的鍵盤操作、狀態管理與視覺呈現。
