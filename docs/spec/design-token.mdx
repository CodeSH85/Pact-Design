Design Token 是設計系統中最小單位的視覺決策記錄。透過將色彩、字級、間距、圓角、陰影與動態時長抽象為具語意的名稱，設計與開發團隊可以共享同一份單一資料來源，確保跨元件、跨頁面與深淺主題之間的高度一致。

---

## 三層式語意架構（Category–Type–Item）

Pact Design 參考 Material 3 的 **Category–Type–Item** 命名語法，將所有 Design Token 統一宣告於 `pd.<tier>.<domain>.*` 命名空間中，並嚴格遵守由下而上的單向參照原則：

| 層級 | CSS 變數前綴 | 職責說明 | 範例 |
| :--- | :--- | :--- | :--- |
| **Global 原始層** | `--pd-global-*` | 儲存不含情境語意的基礎原始值，涵蓋 13 組 OKLCH 色盤、尺寸與間距階梯、字重與動效時間刻度。 | `--pd-global-color-indigo-600`、`--pd-global-spacing-05` |
| **System 語意層** | `--pd-system-*` | 賦予設計意圖與主題感知能力，定義工作區表面、表面文字、語意狀態色、邊框、焦點與複合排版字階。 | `--pd-system-color-surface-layer-1`、`--pd-system-color-on-surface` |
| **Component 元件層** | `--pd-component-*` | 針對特定互動元件的屬性插槽（`bg`、`text`、`border`、`icon`）封裝專屬變數，預設參照 System 層。 | `--pd-component-button-primary-bg-hover`、`--pd-component-field-border-focus` |

## 宣告式原始碼與 W3C DTCG 2025.10 規範

所有原始 Token 皆於 `packages/tokens/src/` 內透過精簡純函式工廠（`factory.ts`）撰寫，檔案目錄與物件結構直接決定最終的命名空間與 CSS 變數名稱，並完全符合 **W3C Design Tokens Community Group 2025.10** 標準（包含 `$value`、`$type` 與群組基準值 `$root`）：

- **單一資料來源**：`tokens = { pd: { global, system, component } }` 的結構與編譯產出的 CSS 變數名稱維持 1:1 對應，建置腳本不包含任何隱性前綴或跨檔合併邏輯。
- **編譯期路徑檢查**：System 層與 Component 層的參照路徑在 TypeScript 型別階段即受檢驗，避免拼寫錯誤或無效參照流入建置產物。
- **DTCG `$root` 群組基準**：語意色彩與群組使用 `$root` 定義預設值（例如 `primary.$root` 與 `primary.strong`），編譯時自動省略 `$root` 區段，輸出 `--pd-system-color-primary` 與 `--pd-system-color-primary-strong`。
- **保留變數參照鏈**：編譯為 CSS Custom Properties 時保留層級間的 `var(--pd-*)` 參照關係，讓主題切換與覆寫能在瀏覽器原生完成。

```ts
// packages/tokens/src/global/color.ts
import { oklchPalette } from '../factory.ts'

export const globalColor = {
  indigo: oklchPalette({
    500: [0.698, 0.1404, 274.9561],
    600: [0.55, 0.192, 274.9733],
    700: [0.468, 0.195, 274.9]
  })
} as const

// packages/tokens/src/system/color.ts
export const systemColor = {
  primary: {
    $root: color({ light: 'indigo.600', dark: 'indigo.700' }),        // 實心填色背景（含白色前景文字）
    vivid: color({ light: 'indigo.600', dark: 'indigo.600' }),        // 飽和填色強調（Switch 啟用軌道）
    strong: color({ light: 'indigo.700', dark: 'indigo.600' }),       // 強化實心色階（供元件 hover 參照）
    stronger: color({ light: 'indigo.800', dark: 'indigo.800' }),     // 最深實心色階（供元件 active 參照）
    subtle: color({ light: 'indigo.100', dark: 'indigo.1000' }),      // 柔和容器背景
    muted: color({ light: 'indigo.200', dark: 'indigo.900' }),        // 中低強調柔和容器
    soft: color({ light: 'indigo.300', dark: 'indigo.800' }),         // 較高強調柔和容器
    text: {
      $root: color({ light: 'indigo.700', dark: 'indigo.400' }),      // 中性表面上的語意文字與圖示
      strong: color({ light: 'indigo.800', dark: 'indigo.300' }),
      stronger: color({ light: 'indigo.900', dark: 'indigo.200' })
    },
    border: {
      $root: color({ light: 'indigo.300', dark: 'indigo.800' }),      // 柔和容器邊框
      strong: color({ light: 'indigo.600', dark: 'indigo.400' })      // 強調指示線與焦點描邊
    }
  }
} as const
```

### 語意色彩角色、透明度與混合式焦點狀態

- **色階與互動狀態解耦**：所有 7 組語意角色（`primary`、`secondary`、`success`、`danger`、`warning`、`info`、`neutral`）在 System 層提供主題自適應的純色階變體——實心填色（`$root` / `strong` / `stronger`）、非文字高對比強調色（`vivid`）、柔和容器（`subtle` / `muted` / `soft`）、中性表面前景（`text.$root` / `strong` / `stronger`）以及邊框（`border.$root` / `strong`），再由 Component 層將 `hover` / `active` 狀態對應至合適色階；同時提供 `surface.control` 供 Switch 與 Slider 靜止軌道使用，避免誤借狀態色。
- **透明度領域與型別安全的 `alpha()`**：透過 `pd.global.opacity.*` 與 `pd.system.opacity.*` 提供標準化透明度階梯；在 `system/color.ts` 中使用 `alpha('indigo.600', '20')` 於建置期解析為標準 DTCG OKLCH 透明度色彩（`oklch(L C H / alpha)`），相容舊版瀏覽器目標與對比測試工具（注意：建置期固化的透明度色值不會隨執行期覆寫 `--pd-global-color-*` 連動，需直接覆寫語意光暈變數）。
- **混合式焦點規範**：鍵盤 `:focus-visible` 在按鈕、分頁、清單與核取元件上維持高對比 `outline`（並提供 `border.focus.danger` 危險焦點色）；表單輸入框與 `SelectTrigger` 則採用 `--pd-system-elevation-focus` / `focus-danger` 柔和焦點光暈，並搭配 `@media (forced-colors: active)` 高對比模式備援外框。

## 單一來源的深淺主題策略

Pact Design 在 System 層透過 `color({ light, dark })` 於同一份定義檔中同步宣告淺色與深色主題對應值，而非拆分兩份容易不同步的設定檔：

- **鍵名完全對稱**：淺色與深色模式天生維持 100% 一致的 Token 名稱與路徑結構，不會在路徑中混入 `light` 或 `dark` 字樣。
- **CSS 選擇器隔離**：建置工具會將預設淺色變數輸出至 `:root, [data-theme="light"]`，深色覆寫變數則輸出至 `[data-theme="dark"]`，只需切換根節點屬性即可完成全站主題切換。

```css
:root, [data-theme="light"] {
  --pd-global-color-indigo-600: oklch(0.6 0.192 274.9733);
  --pd-system-color-primary: var(--pd-global-color-indigo-600);
  --pd-system-color-on-surface: var(--pd-global-color-gray-1100);
}

[data-theme="dark"] {
  --pd-system-color-primary: var(--pd-global-color-indigo-700);
  --pd-system-color-on-surface: var(--pd-global-color-gray-200);
}
```

## 編譯管線與樣式消費

Pact Design 將純資料層與 Web 樣式層拆分為兩個協同套件，讓團隊可依專案架構彈性引入：

1. **`@pact-design/tokens`**：使用 Style Dictionary v5 編譯宣告式 Token 樹，產出全套 `--pd-*` CSS 變數與純淨的 Token 中繼資料清單，並內建自動化 APCA 對比度測試與契約驗證。
2. **`@pact-design/styles`**：消費 `@pact-design/tokens` 產物，透過 Lightning CSS 編譯為開箱即用的分層現代 CSS 樣式表，整合原生深淺色 `color-scheme` 支援、局部重設樣式與各元件語意樣式，亦提供選用的 UnoCSS 預設集供應用程式層排版使用。

```css
/* 引入完整樣式表，包含所有 --pd-* 變數、深淺主題與元件樣式 */
@import '@pact-design/styles/css';
```
