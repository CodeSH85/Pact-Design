色彩在介面中承擔著傳達層次、引導操作與表達狀態的重要任務。在 Pact Design 中，我們對色彩抱持克制的態度：以中性色建構沉穩的工作區結構，將鮮明的彩度保留給關鍵互動與狀態提醒，讓資訊傳達始終清晰而不造成視覺疲勞。

---

## 色彩模型與感知一致

傳統色彩調整容易出現「數值看似均勻，肉眼卻覺得明暗跳躍」的問題，特別是黃色、藍色與綠色在相同明度數值下的視覺亮度落差極大。

Pact Design 採用 **OKLCH** 均勻感知色彩空間來建立色盤。這種方式讓不同色系在同一個色階上擁有相近的視覺亮度，設計師在切換狀態色或調整主題時，能獲得高度一致的心理預期與閱讀對比。所有色階皆經過校準，確保在標準螢幕色域內正確呈現，不產生溢色或失真。

---

## 基礎色盤與中性色

基礎色盤包含 13 組色系，每組由淺至深劃分為 12 個明度色階，並搭配純白與純黑，足以涵蓋從柔和背景到高對比文字的各種介面需求：

- **中性色系**：提供標準灰、冷灰與暖灰三組無彩度與微傾向灰階，廣泛運用於背景、文字、邊框與分隔線。
- **有彩色系**：涵蓋青、藍、靛藍、紫、洋紅、紅、橘、黃、綠與薄荷綠十組色系，作為品牌強調色、功能狀態色與資料視覺化的基礎來源。

色階的中段位置經過對比校準，從中段往深色延伸的色階搭配淺色文字皆具備足夠的可讀性，讓設計者在挑選按鈕底色或標籤色彩時更安心。

---

## 工作區背景層級

高密度介面常包含導覽列、側邊欄、主內容區與浮動視窗等多重區域。Pact Design 透過漸進的明度變化建立清晰的空間層級，無須依賴過多粗線框就能區分區塊關係：

| 層級角色 | 視覺定位 | 常見使用情境 |
| :--- | :--- | :--- |
| **基底畫布** | 介面最底層的承載背景 | 應用程式底層工作區與窗格之間的底色。 |
| **結構框架層** | 與畫布形成柔和區隔的第一層表面 | 頂部導覽列、側邊欄、工具列與屬性檢視面板。 |
| **內容容器層** | 承載主要閱讀與操作內容的表面 | 編輯區、資料表與卡片內容區塊。 |
| **懸浮層** | 浮於工作區之上的前景容器 | 下拉選單、浮動視窗與互動視窗，通常搭配陰影呈現深度。 |
| **遮罩層** | 暫時弱化背後內容的半透明暗層 | 互動視窗或側邊抽屜開啟時的背景覆蓋層。 |
| **停用表面** | 降低視覺存在感的柔和灰階 | 停用狀態的表單輸入框與按鈕底色。 |

## 文字層級與對比

文字是使用者理解內容與完成任務的主要媒介。為了讓資訊具備清楚的主次關係，同時在淺色與深色主題下都能維持舒適閱讀，Pact Design 將表面文字分為四個層級，並以 **APCA** 感知對比度標準進行驗證：

| 文字層級 | 視覺權重 | 常見使用情境 |
| :--- | :--- | :--- |
| **主要文字** | 最高對比度，閱讀最清晰 | 頁面標題、主要內文、資料表核心欄位與重要數值。 |
| **次要文字** | 略微柔和但仍具高可讀性 | 區塊副標、表單標籤與次要補充資訊。 |
| **弱化文字** | 低干擾的輔助層級 | 時間戳記、欄位提示文字、輔助說明與註腳。 |
| **停用文字** | 明確區隔非作用中元素 | 不可點擊的選項、停用狀態的控制項標籤。 |

## 語意與狀態色

Pact Design 定義了七組語意角色，包含主要、次要、成功、危險、警告、資訊與中性，用以表達明確的互動意圖與系統狀態。為了適應不同密度的介面需求，每組語意色皆提供兩種應用模式：

- **實心操作模式**：採用飽滿底色搭配高對比文字，並具備完整的懸停與按下狀態變化。適合用於畫面中最關鍵的行動按鈕與啟用中的控制項。
- **柔和容器模式**：採用同色系淺底搭配深色文字與細緻邊框。適合大量出現在資料表與清單中的狀態標籤、行內提示與分類標記，能清楚傳達狀態又不至於讓整個畫面過於刺眼。

---

## 色彩應用建議

- **維持中性色為主軸**：將 80% 以上的畫面空間留給中性色與背景層級，讓高彩度色彩真正發揮吸引注意力的作用。
- **遵守使用者的色彩直覺**：功能狀態色應在整個產品中保持一致，例如以綠色傳達成功、紅色提示危險或錯誤、橘黃色表達警示，避免隨意更改語意造成誤解。
- **同時檢視淺色與深色主題**：設計介面時請隨時切換深淺主題檢查層次與對比，確保兩種模式下都具備同等清晰的閱讀體驗。
