## 何時使用

- 需要使用者填寫姓名、電子郵件、網址、名稱或簡短數值等單行資料時使用。
- 若輸入內容帶有固定前綴或單位，例如網域名稱、貨幣符號或百分比，可直接使用 `prefix` 與 `suffix` 提示格式，減少使用者重複輸入。
- 若情境專用於搜尋與篩選清單，建議改用內建放大鏡與快速清除按鈕的 **SearchField 搜尋欄位**。

## 使用範例

### 前後綴與尺寸

可透過 `prefix` 與 `suffix` 放入固定字首、圖示或計量單位，並依版面密度選擇合適的高度。

<ComponentPreview align="stretch">

### 驗證錯誤與停用狀態

當輸入內容不符合規範時，搭配 `isInvalid` 與 `errorMessage` 提供明確修正指引；若欄位目前不可修改，可使用 `isDisabled` 或 `isReadOnly`。

<ComponentPreview align="stretch">
  <div className="grid grid-cols-1 md:grid-cols-2 gap-md">
    <TextField
      label="變數前綴"
      isInvalid
      defaultValue="123 invalid"
      errorMessage="前綴必須以小寫英文字母開頭，且不可包含空白。"
    />
    <TextField
      label="套件來源位址"
      isDisabled
      defaultValue="registry.example.com"
    />
  </div>
</ComponentPreview>

```tsx
<TextField

<TextField label="套件來源位址" isDisabled defaultValue="registry.example.com" />
```

## API 參考

### TextField

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於輸入框上方的欄位標籤。 |
| `description` | `ReactNode` | `—` | 顯示於輸入框下方的輔助說明文字。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 欄位無效時顯示的錯誤提示內容。 |
| `prefix` | `ReactNode` | `—` | 位於輸入框內左側的固定圖示或文字。 |
| `suffix` | `ReactNode` | `—` | 位於輸入框內右側的單位、網域或狀態指示。 |
| `placeholder` | `string` | `—` | 輸入框空白時的提示文字。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 輸入框高度與文字比例。 |
| `value` / `defaultValue` | `string` | `—` | 受控或預設的文字內容。 |
| `onChange` | `(value: string) => void` | `—` | 輸入內容變更時觸發的回呼函式。 |
| `inputProps` | `InputProps` | `—` | 傳遞至內層原生輸入元素的屬性，例如 `type` 或 `autoComplete`。 |
| `isDisabled` | `boolean` | `false` | 是否停用輸入互動。 |
| `isInvalid` | `boolean` | `false` | 是否標示為驗證錯誤狀態。 |
| `isReadOnly` | `boolean` | `false` | 是否設為唯讀，保留聚焦與選取文字能力但禁止編輯。 |
