## API Reference

Built on React Aria `Label`, `Group`, `Input`, `Button`, `Text`, and `FieldError`.

### Parts

- **`Label`**: Accessible field label with medium weight and default cursor.
- **`FieldGroup`**: Token-styled input container supporting focus-within, invalid, and disabled states.
- **`Input`**: Transparent flex-1 input reset nested cleanly inside `FieldGroup`.
- **`FieldButton`**: Compact action button styled to sit inside `FieldGroup` edges.
- **`FieldDescription`**: Caption text mapped with `slot="description"`.
- **`FieldError`**: Error message primitive rendered when parent field validation fails.

### FieldGroup

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`), padding, and border radius. |
| `isDisabled` | `boolean` | `false` | Applies disabled surface styling to the group container. |
| `isInvalid` | `boolean` | `false` | Applies invalid danger border tokens. |
| `className` | `string \| ((props) => string)` | `—` | Optional CSS classes merged onto the group container. |

### FieldButton

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `isDisabled` / `disabled` | `boolean` | `false` | Disables interaction and pointer clicks. |
| `onPress` | `(e: PressEvent) => void` | `—` | Unified mouse, touch, and keyboard activation callback. |
| `className` | `string \| ((props) => string)` | `—` | Optional CSS classes merged with inline field button styles. |

### Validation Error State

Pass `isInvalid` on the parent field so `FieldGroup` highlights in danger border tokens and renders `FieldError`.

      <FieldError>Value must be a valid 6-digit hex code.</FieldError>
