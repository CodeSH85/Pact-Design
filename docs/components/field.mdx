## 何時使用

- 一般表單情境優先使用已封裝好的 **TextField 文字輸入框**、**SearchField 搜尋欄位** 或 **DateField 日期欄位**。
- 當介面需要客製化欄位結構時，例如在輸入框右側放置複製按鈕、密碼顯示切換或複合式操作控制項，可直接組合 `Label`、`FieldGroup`、`Input`、`FieldButton`、`FieldDescription` 與 `FieldError` 來保持一致的視覺與無障礙行為。

## 尺寸

## 驗證錯誤狀態

當外層表單欄位進入無效狀態時，外框會自動呈現警示樣式並顯示 `FieldError` 錯誤訊息。

<ComponentPreview>
  <div className="w-full max-w-80">
    <TextField isInvalid defaultValue="invalid-code">
      <Label>Project Code</Label>
      <FieldGroup size="md">
        <Input />
      </FieldGroup>
      <FieldError>Must be at least 6 alphanumeric characters.</FieldError>
    </TextField>
  </div>
</ComponentPreview>

## API 參考

### 組成元件

- **`Label`**：與輸入控制項自動關聯的表單欄位標籤。
- **`FieldGroup`**：包覆輸入框、圖示與行內按鈕的外框容器，管理聚焦、停用與錯誤狀態。
- **`Input`**：置於 `FieldGroup` 內部的單行文字輸入元件。
- **`FieldButton`**：專為輸入框內緣設計的精簡操作按鈕。
- **`FieldDescription`**：顯示於欄位下方的輔助說明文字。
- **`FieldError`**：欄位驗證失敗時自動顯示的錯誤提示文字。

### FieldGroup

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 控制項高度、內距與圓角大小。 |
| `isDisabled` | `boolean` | `false` | 是否套用停用狀態樣式。 |
| `isInvalid` | `boolean` | `false` | 是否套用驗證錯誤的警示外框。 |
| `className` | `string \| ((props) => string)` | `—` | 額外套用的自訂樣式類別。 |

### FieldButton

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `isDisabled` / `disabled` | `boolean` | `false` | 是否停用按鈕互動。 |
| `onPress` | `(e: PressEvent) => void` | `—` | 點擊或透過鍵盤觸發時的回呼函式。 |
| `className` | `string \| ((props) => string)` | `—` | 額外套用的自訂樣式類別。 |
