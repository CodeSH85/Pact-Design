## 何時使用

- 用於標記資料列狀態（例如 `Active`、`Deprecated`、`Synced`）、Token 型別或引用提示（例如 `alias`、`number`），以及輕量化的分類標籤。
- 若標籤需要被使用者點擊切換狀態或篩選條件，請改用 **ToggleButton 切換按鈕**。

## 外觀變體

透過 `variant` 切換柔和底色 `subtle`（預設）、實心高對比 `solid` 與細邊框 `outline` 三種層級。

## 尺寸與圖示

提供 `xs`、`sm`（預設）與 `md` 三種高度與字級比例，並自動將內嵌圖示縮放至合適大小。

## API 參考

### Badge

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `tone` | `'default' \| 'primary' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 徽章的語意色彩角色。 |
| `variant` | `'subtle' \| 'solid' \| 'outline'` | `'subtle'` | 徽章的填充與邊框視覺層級。 |
| `size` | `'xs' \| 'sm' \| 'md'` | `'sm'` | 徽章的內距與字級比例。 |
| `className` | `string` | `—` | 額外套用於徽章上的自訂樣式類別。 |
