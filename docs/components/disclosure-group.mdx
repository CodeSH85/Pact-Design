## 何時使用

- 適合常見問題清單、多段屬性檢視器、側邊篩選條件群組等由多個折疊項目構成的區塊。
- 預設為手風琴模式，展開某一項時會自動收合其他項目；若使用者需要同時對照多個面板內容，可開啟 `allowsMultipleExpanded`。

## 使用範例

### 整合外觀與同時展開多項

設定 `variant="grouped"` 將多個面板收整進單一外框內以細線區隔，搭配 `allowsMultipleExpanded` 讓多個面板能同時維持展開。

<ComponentPreview align="stretch">

    <Disclosure id="general" title="General">

    </Disclosure>

```tsx
<DisclosureGroup variant="grouped" allowsMultipleExpanded defaultExpandedKeys={['general', 'notifications']}>
  <Disclosure id="general" title="General">...</Disclosure>
  <Disclosure id="notifications" title="Notifications">...</Disclosure>
  <Disclosure id="danger" title="Danger Zone">...</Disclosure>
</DisclosureGroup>
```

### 資料陣列快速生成

當每個折疊項目結構一致時，可直接傳入 `items` 陣列省去重複撰寫子元件標籤。

<ComponentPreview align="stretch">
  <DisclosureGroup
    items={[
      { id: 'sla', title: 'Service Level', content: 'Continuous uptime monitoring and automated alerting.' },
      { id: 'backup', title: 'Backup Policy', content: 'Encrypted daily snapshots retained for 30 days.' }
    ]}
  />
</ComponentPreview>

```tsx
<DisclosureGroup
  items={[
    { id: 'sla', title: 'Service Level', content: 'Continuous uptime monitoring and automated alerting.' },
    { id: 'backup', title: 'Backup Policy', content: 'Encrypted daily snapshots retained for 30 days.' }
  ]}
/>
```

## API 參考

### DisclosureGroup

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'separated' \| 'grouped'` | `'separated'` | `separated` 呈現帶間距的獨立外框項目，`grouped` 則合併為單一外框並以細線分隔。 |
| `items` | `DisclosureGroupItemData[]` | `—` | 資料驅動陣列，每筆包含 `id`、`title`、`content` 與 `isDisabled`。 |
| `allowsMultipleExpanded` | `boolean` | `false` | 是否允許同時展開多個折疊面板。 |
| `expandedKeys` / `defaultExpandedKeys` | `Iterable<Key>` | `—` | 受控或預設展開的面板識別鍵集合。 |
| `onExpandedChange` | `(keys: Set<Key>) => void` | `—` | 展開項目集合變更時觸發的回呼函式。 |
| `isDisabled` | `boolean` | `false` | 一次停用群組內所有折疊面板。 |
