## API Reference

Built on React Aria `DisclosureGroup`. Exports `DisclosureGroup`, `disclosureGroupVariants`, and `DisclosureGroupItemData`.

### DisclosureGroup

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'separated' \| 'grouped'` | `'separated'` | Separated bordered items with gaps, or a unified container with `divide-y` hairlines. |
| `items` | `DisclosureGroupItemData[]` | `—` | Data-driven items array (`{ id, title, content, isDisabled? }`). |
| `allowsMultipleExpanded` | `boolean` | `false` | Permits more than one `Disclosure` panel to stay expanded simultaneously. |
| `expandedKeys` / `defaultExpandedKeys` | `Iterable<Key>` | `—` | Controlled or initial set of expanded item IDs. |
| `onExpandedChange` | `(keys: Set<Key>) => void` | `—` | Handler fired when expanded keys change. |
| `isDisabled` | `boolean` | `false` | Disables all child disclosures. |

## Examples

### Grouped Variant & Multi-Expand

Set `variant="grouped"` to collapse outer item borders into one crisp divided surface, and enable `allowsMultipleExpanded` when panels can remain open together.

<ComponentPreview align="stretch">
  <DisclosureGroup variant="grouped" allowsMultipleExpanded defaultExpandedKeys={['global', 'system']}>
    <Disclosure id="global" title="Global Layer">
      Raw OKLCH palettes, numeric dimensions, durations, and easing curves.
    </Disclosure>
    <Disclosure id="system" title="System Layer">
      Light and dark theme semantic surfaces, ink contrast roles, and focus rings.
    </Disclosure>
    <Disclosure id="component" title="Component Layer">
      Scoped component height, padding, and state overrides referencing System tokens.
    </Disclosure>
  </DisclosureGroup>
</ComponentPreview>

```tsx
<DisclosureGroup variant="grouped" allowsMultipleExpanded defaultExpandedKeys={['global', 'system']}>
  <Disclosure id="global" title="Global Layer">...</Disclosure>
  <Disclosure id="system" title="System Layer">...</Disclosure>
  <Disclosure id="component" title="Component Layer">...</Disclosure>
</DisclosureGroup>
```

### Data-Driven Items

Pass an `items` array directly for concise accordion lists.
