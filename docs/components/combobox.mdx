## 何時使用

- 當可選清單項目較多，例如國家地區、時區、成員名單或專案分類，讓使用者直接打字篩選能大幅縮短尋找時間。
- 若選項數量不多且不需輸入篩選，建議使用結構更單純的 **Select 下拉選單**。
- 若清單本身需要常駐展開於頁面或面板內並即時過濾，建議改用 **Autocomplete 自動完成**。

## 使用範例

### 尺寸

支援五階高度比例，可配合工具列或表單整體密度彈性調整。

      <ComboBoxItem id="lg">LG</ComboBoxItem>
    </ComboBox>
  </div>

```tsx
<ComboBox label="Size SM" size="sm" defaultSelectedKey="xs">
```

### 選項分組與停用狀態

可搭配 `ComboBoxSection` 與 `ListBoxHeader` 將候選清單分門別類，或透過 `isDisabled` 鎖定欄位。

## API 參考

### ComboBox

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於欄位上方的標籤文字。 |
| `description` | `ReactNode` | `—` | 顯示於欄位下方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 欄位無效時顯示的錯誤提示。 |
| `placeholder` | `string` | `—` | 輸入框空白時的提示文字。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 欄位高度與內距大小。 |
| `items` | `Iterable<T>` | `—` | 動態選項資料集合，可搭配渲染函式使用。 |
| `selectedKey` / `defaultSelectedKey` | `Key \| null` | `—` | 受控或預設選取的項目鍵值。 |
| `onSelectionChange` | `(key: Key \| null) => void` | `—` | 選取項目變更時觸發的回呼函式。 |
| `inputProps` | `InputProps` | `—` | 傳遞至內層輸入框的額外屬性。 |
| `popoverProps` | `ComboBoxPopoverProps` | `—` | 傳遞至下拉浮動視窗的額外屬性。 |
| `listBoxProps` | `ListBoxProps<T>` | `—` | 傳遞至下拉選項清單的額外屬性。 |
| `isDisabled` | `boolean` | `false` | 是否停用輸入與下拉展開。 |

### 子元件

- **`ComboBoxItem`**：清單中的單一候選項目。
- **`ComboBoxSection`**：將相關選項歸類的分組容器。
- **`ComboBoxPopover`**：承載下拉清單的浮動容器。
- **`ComboBoxListBox`**：內層可鍵盤導覽的選項清單。
