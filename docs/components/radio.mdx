## 何時使用

- 當所有選項彼此互斥、僅能選擇其中一項，且選項數量約在 2 至 5 個之間時，使用單選按鈕能讓使用者一次看清全部選擇並直接比較。
- 若選項超過 5 個或版面空間有限，建議改用 **Select 下拉選單**。
- 若選項之間可同時複選，請改用 **Checkbox 核取方塊**。

## 水平排列與停用選項

透過 `orientation="horizontal"` 將選項橫向展開，並可針對單一選項設定 `disabled` 表示暫時不可選取。

## API 參考

### RadioGroup

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 群組標題文字。 |
| `description` | `ReactNode` | `—` | 顯示於選項上方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 驗證失敗時顯示的錯誤提示。 |
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | 選項的排列方向。 |
| `value` / `defaultValue` | `string` | `—` | 受控或預設選取的選項值。 |
| `onChange` | `(value: string) => void` | `—` | 選取項目改變時觸發的回呼函式。 |
| `isDisabled` | `boolean` | `false` | 一次停用群組內所有單選項目。 |

### Radio

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `value` | `string` | 必填 | 此選項對應的值，由外層 `RadioGroup` 管理。 |
| `label` | `ReactNode` | `—` | 顯示於圓點旁的主要選項文字。 |
| `description` | `ReactNode` | `—` | 顯示於選項文字下方的補充說明。 |
| `isDisabled` / `disabled` | `boolean` | `false` | 是否停用此單一選項。 |
| `className` | `string` | `—` | 額外套用的自訂樣式類別。 |
