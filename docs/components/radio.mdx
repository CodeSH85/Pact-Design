## API Reference

Built on React Aria `RadioGroup` and `Radio`. Exports `Radio` and `RadioGroup`.

### RadioGroup

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | Accessible group heading label. |
| `description` | `ReactNode` | `—` | Supporting text displayed above radio options. |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | Validation error text when required or invalid. |
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | Layout axis for nested `Radio` controls. |
| `value` / `defaultValue` | `string` | `—` | Controlled or initial selected option value. |
| `onChange` | `(value: string) => void` | `—` | Handler called when selected radio value changes. |
| `isDisabled` | `boolean` | `false` | Disables all options in the group. |

### Radio

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `string` | Required | Option value emitted by enclosing `RadioGroup`. |
| `label` | `ReactNode` | `—` | Primary label shown next to the radio circle. |
| `description` | `ReactNode` | `—` | Secondary description text below `label`. |
| `isDisabled` / `disabled` | `boolean` | `false` | Disables individual radio selection. |
| `className` | `string` | `—` | Optional CSS classes for the root radio label. |

## Examples

### Orientation & Disabled Options

Arrange options horizontally with `orientation="horizontal"` or lock specific choices via `disabled`.

      <Radio value="light" label="Light Mode" />
      <Radio value="dark" label="Dark Mode" />
      <Radio value="high-contrast" label="High Contrast (Soon)" disabled />
    </RadioGroup>
  </div>
</ComponentPreview>
