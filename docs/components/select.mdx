## 何時使用

- 適合用於 5 個以上固定選項的單選情境，或版面空間有限、不適合將所有選項攤開顯示的篩選列與表單。
- 若選項數量很少且希望讓使用者一眼看清全部選擇，建議改用 **Radio 單選按鈕**。
- 若選項清單非常長、需要讓使用者直接輸入文字過濾，建議改用 **ComboBox 組合方塊**。

### 選項分組與停用狀態

當選項具有明確分類時，可使用 `SelectSection`、`SelectHeader` 與 `SelectSeparator` 建立清晰的階層結構。

        <SelectItem id="30d">最近 30 天</SelectItem>

## API 參考

### Select

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於選單上方的欄位標籤。 |
| `description` | `ReactNode` | `—` | 顯示於選單下方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 驗證失敗時顯示的錯誤提示。 |
| `placeholder` | `string` | `'Select an option'` | 尚未選取任何項目時顯示的提示文字。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 觸發按鈕的高度與內距大小。 |
| `items` | `Iterable<T>` | `—` | 動態選項資料集合，可搭配渲染函式使用。 |
| `selectedKey` / `defaultSelectedKey` | `Key \| null` | `—` | 受控或預設選取的項目鍵值。 |
| `onSelectionChange` | `(key: Key \| null) => void` | `—` | 選取項目變更時觸發的回呼函式。 |
| `triggerProps` | `ButtonProps` | `—` | 傳遞至內層觸發按鈕的額外屬性。 |
| `popoverProps` | `SelectPopoverProps` | `—` | 傳遞至展開浮動視窗的額外屬性。 |
| `listBoxProps` | `ListBoxProps<T>` | `—` | 傳遞至展開選項清單的額外屬性。 |
| `isDisabled` | `boolean` | `false` | 是否停用下拉選單。 |

### 子元件

- **`SelectItem`**：下拉清單中的單一選項。
- **`SelectSection`**：將相關選項歸納為同一群組。
- **`SelectHeader`**：群組頂部的分類標題。
- **`SelectSeparator`**：分隔不同群組的細線。
