## API Reference

Built on React Aria `Select` and `ListBox`. Exports `Select`, `SelectItem`, `SelectSection`, `SelectHeader`, `SelectSeparator`, `SelectTrigger`, `SelectValue`, `SelectPopover`, and `SelectListBox`.

### Select

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | Accessible label rendered above the trigger button. |
| `description` | `ReactNode` | `—` | Supporting caption displayed below the select button. |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | Error text shown when validation fails. |
| `placeholder` | `string` | `'Select an option'` (React Aria default) | Placeholder displayed when no key is selected. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`) applied to `SelectTrigger`. |
| `items` | `Iterable<T>` | `—` | Optional dynamic item collection paired with a render function child. |
| `selectedKey` / `defaultSelectedKey` | `Key \| null` | `—` | Controlled or initial selected option key. |
| `onSelectionChange` | `(key: Key \| null) => void` | `—` | Handler fired when an option is selected. |
| `triggerProps` | `AriaButtonProps` | `—` | Additional props passed to `SelectTrigger`. |
| `popoverProps` | `SelectPopoverProps` | `—` | Additional props passed to `SelectPopover`. |
| `listBoxProps` | `AriaListBoxProps<T>` | `—` | Additional props passed to `SelectListBox`. |
| `isDisabled` | `boolean` | `false` | Disables opening the select menu. |
