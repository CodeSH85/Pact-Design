## API Reference

Built on React Aria `Tree`, `TreeItem`, `TreeItemContent`, `Collection`, `TreeSection`, and `TreeHeader`.

### Tree

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `selectionMode` | `'none' \| 'single' \| 'multiple'` | `'none'` | Enables single-row selection or renders inline `Checkbox` items when `'multiple'`. |
| `expandedKeys` / `defaultExpandedKeys` | `Iterable<Key>` | `—` | Controlled or initial expanded parent item IDs. |
| `onExpandedChange` | `(keys: Set<Key>) => void` | `—` | Handler called when branches expand or collapse. |
| `selectedKeys` / `defaultSelectedKeys` | `'all' \| Iterable<Key>` | `—` | Controlled or initial selected tree row IDs. |
| `onSelectionChange` | `(keys: Selection) => void` | `—` | Callback fired when item selection changes. |
| `disabledKeys` | `Iterable<Key>` | `—` | Disables expansion and selection for matching row keys. |

### Parts

- **`TreeItem`**: Represents a single row node. Automatically indents by depth (`level`) and accepts nested child `TreeItem` elements. Always supply `textValue` for keyboard typeahead and ARIA labels.
- **`TreeItemContent`**: Renders the optional `Checkbox` (`slot="selection"`), rotating expand chevron (`slot="chevron"`), and truncated item label.
- **`TreeSection`** & **`TreeHeader`**: Optional grouped section primitives.

### Expand-Only File Explorer

Omit `selectionMode` (or use `selectionMode="single"`) when using `Tree` for read-only navigation hierarchies.
