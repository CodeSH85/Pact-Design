## 何時使用

- 適合呈現資料夾目錄、組織架構、分類樹、圖層面板等具有明確父子隸屬關係的資訊結構。
- 使用者可透過滑鼠點擊箭頭或鍵盤左右方向鍵展開與收合分支，上下方向鍵快速移動焦點。
- 當介面需要一次批次選取多個階層項目，例如選擇要匯出的檔案或設定權限範圍，可開啟 `selectionMode="multiple"` 自動顯示核取方塊。

## 使用範例

## API 參考

### Tree

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `selectionMode` | `'none' \| 'single' \| 'multiple'` | `'none'` | 設定無選取、單選，或啟用複選核取方塊。 |
| `expandedKeys` / `defaultExpandedKeys` | `Iterable<Key>` | `—` | 受控或預設展開的父節點識別鍵集合。 |
| `onExpandedChange` | `(keys: Set<Key>) => void` | `—` | 節點展開或收合時觸發的回呼函式。 |
| `selectedKeys` / `defaultSelectedKeys` | `'all' \| Iterable<Key>` | `—` | 受控或預設選取的節點識別鍵集合。 |
| `onSelectionChange` | `(keys: Selection) => void` | `—` | 選取節點變更時觸發的回呼函式。 |
| `disabledKeys` | `Iterable<Key>` | `—` | 指定停用展開與選取的節點鍵值集合。 |

### 子元件

- **`TreeItem`**：單一樹狀節點，會依巢狀深度自動計算縮排並可包覆子 `TreeItem`。請務必提供 `textValue` 以支援鍵盤字首搜尋與螢幕閱讀器朗讀。
- **`TreeItemContent`**：負責渲染節點列的核取方塊、展開收合箭頭與文字標籤。
- **`TreeSection`** 與 **`TreeHeader`**：選用的分組容器與標題。
