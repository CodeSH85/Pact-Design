## 何時使用

- 適合置於側邊面板、浮動視窗或雙欄穿梭選取器中，直接呈現可供單選或複選的項目清單。
- 選取項目右側會自動顯示勾選標記，並完整支援鍵盤上下鍵瀏覽與字首快速定位。
- 若希望清單平時收合為單一按鈕、點擊時才展開，請改用 **Select 下拉選單**；若點擊項目是為了立即觸發動作指令而非維護選取狀態，請改用 **Menu 選單**。

## 複選與分組結構

開啟 `selectionMode="multiple"` 允許同時選取多項，並透過 `ListBoxSection`、`ListBoxHeader` 與 `ListBoxSeparator` 整理分類。

## API 參考

### ListBox

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `surface` | `'plain' \| 'bordered'` | `'plain'` | `plain` 適合嵌於浮動容器內，`bordered` 則呈現帶外框的獨立清單卡片。 |
| `selectionMode` | `'none' \| 'single' \| 'multiple'` | `'none'` | 設定是否啟用單選或複選與勾選指示。 |
| `selectedKeys` / `defaultSelectedKeys` | `'all' \| Iterable<Key>` | `—` | 受控或預設已選取的項目鍵值集合。 |
| `onSelectionChange` | `(keys: Selection) => void` | `—` | 選取狀態改變時觸發的回呼函式。 |
| `onAction` | `(key: Key) => void` | `—` | 點擊或按下 `Enter` 觸發單一項目時的回呼函式。 |
| `disabledKeys` | `Iterable<Key>` | `—` | 指定停用的項目鍵值集合。 |

### 子元件

- **`ListBoxItem`**：清單中的單一項目，選取時自動於右側顯示勾選圖示。
- **`ListBoxSection`**：將關聯選項歸納為同一分組。
- **`ListBoxHeader`**：分組頂部的分類標題。
- **`ListBoxSeparator`**：分隔不同分組的水平細線。
