## API Reference

Built on React Aria `Autocomplete` and `useFilter({ sensitivity: 'base' })`. Exports `Autocomplete`, `AutocompleteItem`, `AutocompleteSearchField`, `AutocompleteListBox`, and `useFilter`.

### Autocomplete

When `label`, `placeholder`, or `searchFieldProps` is provided, renders an `AutocompleteSearchField` paired with an `AutocompleteListBox`. Otherwise, accepts custom composable children.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | Accessible label rendered above the search input. |
| `description` | `ReactNode` | `—` | Helper text rendered below the list box. |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | Validation error text displayed when invalid. |
| `placeholder` | `string` | `—` | Placeholder text forwarded to `AutocompleteSearchField`. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height scale for the embedded search field. |
| `filter` | `(textValue: string, inputValue: string) => boolean` | `useFilter({ sensitivity: 'base' }).contains` | Custom item filter predicate. |
| `searchFieldProps` | `Partial<SearchFieldProps>` | `—` | Props forwarded to `AutocompleteSearchField`. |
| `listBoxProps` | `Partial<AutocompleteListBoxProps<T>>` | `—` | Props forwarded to `AutocompleteListBox` (such as `onAction`, `selectionMode`, `onSelectionChange`). |
| `className` | `string` | `—` | Optional CSS classes for the outer field wrapper. |

### Parts

- **`AutocompleteItem`**: Renders a `ListBoxItem` inside `AutocompleteListBox`.
- **`AutocompleteSearchField`**: Wrapper around `SearchField` wired into React Aria `Autocomplete` context.
- **`AutocompleteListBox`**: Bordered `ListBox` (`surface="bordered"`) filtered by the current query.

Adjust the search field density with `size` (`sm`, `md`, `lg`).

### Custom Composition

Omit shorthand field props to supply custom `AutocompleteSearchField` and `AutocompleteListBox` children directly.

<ComponentPreview>
  <div className="w-full max-w-80">
    <Autocomplete>
      <AutocompleteSearchField aria-label="Custom search" placeholder="Search commands..." />
      <AutocompleteListBox selectionMode="single">
        <AutocompleteItem id="build">pnpm build:tokens</AutocompleteItem>
        <AutocompleteItem id="lint">pnpm lint</AutocompleteItem>
        <AutocompleteItem id="typecheck">pnpm typecheck</AutocompleteItem>
      </AutocompleteListBox>
    </Autocomplete>
  </div>
</ComponentPreview>

```tsx
<Autocomplete>
```
