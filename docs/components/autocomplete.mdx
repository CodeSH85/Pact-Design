## 何時使用

- 適合指令面板、側邊快速跳轉面板、篩選清單或抽屜內的搜尋選取情境，清單直接呈現於搜尋欄下方並隨輸入即時過濾。
- 若希望清單平時收合、僅於點擊輸入框時以浮動視窗展開，建議改用 **ComboBox 組合方塊**。

### 自訂組合結構

不傳入簡寫屬性時，可直接組合 `AutocompleteSearchField` 與 `AutocompleteListBox`，自由設定選取模式與清單行為。

## API 參考

### Autocomplete

傳入 `label`、`placeholder` 或 `searchFieldProps` 時會自動組合搜尋欄位與帶框選項清單；省略時可自行傳入子元件。

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於搜尋欄位上方的標籤文字。 |
| `description` | `ReactNode` | `—` | 顯示於搜尋欄位下方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 欄位無效時顯示的錯誤提示。 |
| `placeholder` | `string` | `—` | 傳遞至內嵌搜尋欄位的提示文字。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 內嵌搜尋欄位的高度尺寸。 |
| `filter` | `(textValue: string, inputValue: string) => boolean` | 不分大小寫包含比對 | 自訂清單項目的過濾條件函式。 |
| `searchFieldProps` | `Partial<SearchFieldProps>` | `—` | 傳遞至內嵌搜尋欄位的額外屬性。 |
| `listBoxProps` | `Partial<AutocompleteListBoxProps<T>>` | `—` | 傳遞至選項清單的額外屬性，例如 `onAction` 與 `selectionMode`。 |
| `className` | `string` | `—` | 額外套用於外層容器的自訂樣式類別。 |

### 子元件

- **`AutocompleteItem`**：清單中的單一可篩選項目。
- **`AutocompleteSearchField`**：與自動完成狀態連動的搜尋輸入欄位。
- **`AutocompleteListBox`**：即時呈現過濾結果的帶框選項清單。
