## API Reference

Built on React Aria `Breadcrumbs`, `Breadcrumb`, and `Link`. Exports `Breadcrumbs`, `Breadcrumb`, `BreadcrumbLink`, and `BreadcrumbSeparator`.

### Breadcrumbs

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `items` | `BreadcrumbItemData[]` | `—` | Declarative breadcrumb entries (`{ id?, label, href?, isDisabled? }`). |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Typography and gap scale for breadcrumb items. |
| `isDisabled` | `boolean` | `false` | Disables interaction across all items. |
| `onAction` | `(key: Key) => void` | `—` | Handler called when a breadcrumb link is activated. |
| `className` | `string` | `—` | Optional CSS classes for the root list. |

### Breadcrumb

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `separator` | `ReactNode \| boolean` | `true` | Displays default chevron (`true`), custom separator element, or hides it (`false`). Automatically omitted on the last (`data-current`) item. |
| `className` | `string` | `—` | Optional CSS classes for the item container. |

### Custom Composition & Separators

Use `Breadcrumb`, `BreadcrumbLink`, and custom `separator` nodes for bespoke trails or disabled steps.

<ComponentPreview>
  <Breadcrumbs>
    <Breadcrumb separator={<span className="text-on-surface-disabled px-3xs">/</span>}>
      <BreadcrumbLink href="#root">Workspace</BreadcrumbLink>
    </Breadcrumb>
    <Breadcrumb separator={<span className="text-on-surface-disabled px-3xs">/</span>}>
      <BreadcrumbLink href="#archive" isDisabled>Archived</BreadcrumbLink>
    </Breadcrumb>
    <Breadcrumb>
      <BreadcrumbLink>Audit Report</BreadcrumbLink>
    </Breadcrumb>
  </Breadcrumbs>
</ComponentPreview>

```tsx
import { Breadcrumb, BreadcrumbLink, Breadcrumbs } from '@pact-design/react'

<Breadcrumbs>
  <Breadcrumb separator={<span>/</span>}>
    <BreadcrumbLink href="#root">Workspace</BreadcrumbLink>
  </Breadcrumb>
  <Breadcrumb separator={<span>/</span>}>
    <BreadcrumbLink href="#archive" isDisabled>Archived</BreadcrumbLink>
  </Breadcrumb>
  <Breadcrumb>
    <BreadcrumbLink>Audit Report</BreadcrumbLink>
  </Breadcrumb>
</Breadcrumbs>
```
