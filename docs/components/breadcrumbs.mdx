## 何時使用

- 當系統具有兩層以上的頁面結構、檔案目錄或分類層級，需要幫助使用者快速確認目前所處位置時使用。
- 讓使用者能直接跳回任意上層目錄，而不必多次點擊瀏覽器的上一頁。
- 麵包屑應作為輔助導覽使用，不應取代主導覽列；最後一項代表目前所在頁面，預設不作為可點擊連結。

## 使用範例

### 尺寸

透過 `size` 調整文字大小與項目間距，配合緊湊工具列或一般頁面標頭。

<ComponentPreview align="stretch">
  <div className="flex flex-col gap-md items-center">
    <Breadcrumbs
      size="sm"
      items={[
        { id: 's-1', label: 'Workspace', href: '#workspace' },
        { id: 's-2', label: 'Settings', href: '#settings' },
        { id: 's-3', label: 'SM' }
      ]}
    />
    <Breadcrumbs
      size="md"
      items={[
        { id: 'm-1', label: 'Workspace', href: '#workspace' },
        { id: 'm-2', label: 'Settings', href: '#settings' },
        { id: 'm-3', label: 'MD' }
      ]}
    />
    <Breadcrumbs
      size="lg"
      items={[
        { id: 'l-1', label: 'Workspace', href: '#workspace' },
        { id: 'l-2', label: 'Settings', href: '#settings' },
        { id: 'l-3', label: 'LG' }
      ]}
    />
  </div>
</ComponentPreview>

```tsx
<Breadcrumbs size="sm" items={[...]} />
<Breadcrumbs size="md" items={[...]} />
<Breadcrumbs size="lg" items={[...]} />
```

### 自訂分隔符號與停用節點

除了直接傳入 `items` 陣列，也可組合 `Breadcrumb` 與 `BreadcrumbLink` 自訂斜線等分隔符號，或將特定中繼層級設為停用。

<ComponentPreview>
  <Breadcrumbs>
    <Breadcrumb separator={<span className="text-on-surface-disabled px-3xs">/</span>}>
      <BreadcrumbLink href="#root">Workspace</BreadcrumbLink>
    </Breadcrumb>
    <Breadcrumb separator={<span className="text-on-surface-disabled px-3xs">/</span>}>
      <BreadcrumbLink href="#archive" isDisabled>Disabled</BreadcrumbLink>
    </Breadcrumb>
    <Breadcrumb>
      <BreadcrumbLink>Current</BreadcrumbLink>
    </Breadcrumb>
  </Breadcrumbs>
</ComponentPreview>

```tsx
import { Breadcrumb, BreadcrumbLink, Breadcrumbs } from '@pact-design/react'

<Breadcrumbs>
  <Breadcrumb separator={<span>/</span>}>
    <BreadcrumbLink href="#root">Workspace</BreadcrumbLink>
  </Breadcrumb>
  <Breadcrumb separator={<span>/</span>}>
    <BreadcrumbLink href="#archive" isDisabled>Disabled</BreadcrumbLink>
  </Breadcrumb>
  <Breadcrumb>
    <BreadcrumbLink>Current</BreadcrumbLink>
  </Breadcrumb>
</Breadcrumbs>
```

## API 參考

### Breadcrumbs

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `items` | `BreadcrumbItemData[]` | `—` | 聲明式路徑資料陣列，每筆包含 `id`、`label`、`href` 與 `isDisabled`。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 路徑文字與項目間距大小。 |
| `isDisabled` | `boolean` | `false` | 一次停用所有路徑連結。 |
| `onAction` | `(key: Key) => void` | `—` | 點擊或觸發任意路徑連結時的回呼函式。 |
| `className` | `string` | `—` | 額外套用於外層清單的自訂樣式類別。 |

### Breadcrumb

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `separator` | `ReactNode \| boolean` | `true` | 設為 `true` 顯示預設箭頭，傳入節點可自訂分隔符號，設為 `false` 則隱藏；最後一項會自動省略分隔符號。 |
| `className` | `string` | `—` | 額外套用於單一項目的自訂樣式類別。 |
