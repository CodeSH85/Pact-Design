## API Reference

Built on React Aria `UNSTABLE_ToastRegion`, `UNSTABLE_Toast`, `UNSTABLE_ToastContent`, and `UNSTABLE_ToastQueue`. Exports `Toast`, `ToastRegion`, `ToastContent`, `ToastList`, `toast`, `toastQueue`, and `toastVariants`.

### toast()

Helper backed by singleton `toastQueue` (`maxVisibleToasts: 5`):

- `toast(content: ToastData | string, options?: ToastOptions)`
- `toast.info(title: string, description?: string, options?: ToastOptions)`
- `toast.success(title: string, description?: string, options?: ToastOptions)`
- `toast.warning(title: string, description?: string, options?: ToastOptions)`
- `toast.danger(title: string, description?: string, options?: ToastOptions)`

### Toast

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `tone` | `'default' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Maps background, border, text, and leading Remix status icon to semantic tokens. |
| `toast` | `QueuedToast<T>` | Required | Queued toast item passed from `ToastRegion` render callback. |
| `className` | `string` | `—` | Additional CSS classes merged onto the toast card. |

### ToastRegion

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `queue` | `UNSTABLE_ToastQueue<T>` | `toastQueue` | Custom queue instance when isolated toast regions are needed. |
| `children` | `(renderProps: { toast: QueuedToast<T> }) => ReactElement` | Default `Toast` card renderer | Custom toast item renderer overriding default `title`/`description` layout. |
| `className` | `string` | Bottom-right fixed stack (`z-toast`) | Overrides toast region positioning classes. |
