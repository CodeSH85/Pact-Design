## 何時使用

- 適合提供輕量、不中斷目前操作流程的即時回饋，例如「已儲存變更」、「已複製到剪貼簿」、「匯出失敗請重試」。
- 提供標準、資訊、成功、警告與危險五種語意風格，並自動搭配對應狀態圖示與關閉按鈕。
- 由於通知會在短時間後自動消失，請勿將需要使用者反覆查閱的重要資訊或必須立刻決策的警示僅放於通知中；重要決策應改用 **Modal 互動視窗**。

## 語意風格

可透過 `toast.info`、`toast.success`、`toast.warning`、`toast.danger` 或預設的 `toast` 函式快速送出不同語意層級的通知。

```tsx
toast.info('Info', 'A new workspace update is available.')
toast.success('Success', 'All changes have been saved.')
toast.warning('Warning', 'High latency detected. Retrying automatically.')
toast.danger('Danger', 'Export failed. Please try again.')
```

## API 參考

### toast 呼叫函式

透過全域佇列觸發通知，同時最多顯示 5 則訊息：

- `toast(content: ToastData | string, options?: ToastOptions)`
- `toast.info(title: string, description?: string, options?: ToastOptions)`
- `toast.success(title: string, description?: string, options?: ToastOptions)`
- `toast.warning(title: string, description?: string, options?: ToastOptions)`
- `toast.danger(title: string, description?: string, options?: ToastOptions)`

### Toast

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `tone` | `'default' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 通知的語意風格與對應狀態圖示。 |
| `toast` | `QueuedToast<T>` | 必填 | 由 `ToastRegion` 佇列傳入的通知資料物件。 |
| `className` | `string` | `—` | 額外套用於通知卡片的自訂樣式類別。 |

### ToastRegion

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `queue` | `ToastQueue<T>` | 全域 `toastQueue` | 需建立獨立通知佇列時傳入的自訂佇列實例。 |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end'` | `'bottom-end'` | 設定通知區域於視窗的顯示位置。 |
| `children` | `(renderProps: { toast: QueuedToast<T> }) => ReactElement` | 預設 `Toast` 卡片 | 自訂每則通知的渲染結構。 |
| `className` | `string` | `—` | 覆寫通知區域的位置或外層樣式。 |
