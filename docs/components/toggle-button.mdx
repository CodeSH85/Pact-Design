## 何時使用

- **單一狀態切換**：適合工具列中的釘選、靜音、收藏、顯示網格等可反覆開關的功能。
- **分段檢視切換**：搭配 `ToggleButtonGroup` 使用，適合在清單、網格、表格等檢視模式之間切換，或作為文字粗體、斜體等複選格式工具列。

若操作對象屬於表單設定項目且需要搭配說明文字，建議改用 **Switch 開關**。

## 視覺層級

支援 `secondary`、`ghost` 與 `primary` 三種樣式，點擊即可觀察選取與未選取狀態的視覺差異。

  <ToggleButton variant="ghost" defaultSelected>Ghost</ToggleButton>
  <ToggleButton variant="primary" defaultSelected>Primary</ToggleButton>
  <ToggleButton variant="secondary" disabled>Disabled</ToggleButton>
</ComponentPreview>

## 分段單選與多選

透過 `ToggleButtonGroup` 將多個切換按鈕緊密組合。設定 `selectionMode="single"` 並加上 `disallowEmptySelection` 時，非常適合用於檢視模式或主題切換；設定 `selectionMode="multiple"` 則可同時啟用多項條件。

      <ToggleButton id="grid" size="sm" variant="primary">Grid</ToggleButton>

  </div>
</ComponentPreview>

## 純圖示切換 (`icon`)

設定 `icon` 屬性可建立等寬高的工具列圖示切換按鈕，內嵌圖示會依 `size` 自動縮放；搭配 `TooltipTrigger` 使用即可提供明確的功能提示。

<ComponentPreview>
  <ToggleButton variant="ghost" size="sm" icon defaultSelected aria-label="書籤">
    <RiBookmarkLine />
  </ToggleButton>
  <ToggleButton variant="secondary" size="sm" icon aria-label="檢視原始碼">
    <RiCodeSSlashLine />
  </ToggleButton>

    <ToggleButton id="grid" size="sm" icon aria-label="格狀檢視">

</ComponentPreview>

## API 參考

### ToggleButton

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'secondary' \| 'ghost' \| 'primary'` | `'secondary'` | 切換按鈕在未選取與選取狀態下的視覺樣式。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 控制項高度與內距大小。 |
| `radius` | `'none' \| '2xs' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `—` | 自訂邊框圓角，置於群組內時由群組自動銜接。 |
| `icon` | `boolean` | `false` | 設為 `true` 時將水平內距歸零並固定為等寬高正方形純圖示切換按鈕。 |
| `isSelected` | `boolean` | `—` | 受控模式下的選取狀態。 |
| `defaultSelected` | `boolean` | `false` | 非受控模式下的預設選取狀態。 |
| `onChange` | `(isSelected: boolean) => void` | `—` | 選取狀態改變時觸發的回呼函式。 |
| `isDisabled` / `disabled` | `boolean` | `false` | 是否停用按鈕互動。 |
| `id` | `Key` | `—` | 位於 `ToggleButtonGroup` 中時的項目識別鍵。 |

### ToggleButtonGroup

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `selectionMode` | `'single' \| 'multiple'` | `'single'` | 設定群組為單選或複選模式。 |
| `disallowEmptySelection` | `boolean` | `false` | 防止取消最後一個選取項目，確保恆有一項處於啟用狀態。 |
| `selectedKeys` / `defaultSelectedKeys` | `Iterable<Key>` | `—` | 受控或預設的已選取項目鍵值集合。 |
| `onSelectionChange` | `(keys: Set<Key>) => void` | `—` | 選取項目變更時觸發的回呼函式。 |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 群組內按鈕的排列方向。 |
| `isDisabled` | `boolean` | `false` | 一次停用群組內所有切換按鈕。 |
