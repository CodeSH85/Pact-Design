## API Reference

Built on React Aria `ToggleButton` and `ToggleButtonGroup`. Exports `ToggleButton`, `ToggleButtonGroup`, and `toggleButtonVariants`.

### ToggleButton

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'secondary' \| 'ghost' \| 'primary'` | `'secondary'` | Visual treatment for unselected and `data-[selected]` pressed states. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`) shared with `Button`. |
| `isSelected` | `boolean` | `—` | Controlled pressed/selected state. |
| `defaultSelected` | `boolean` | `false` | Initial toggle state for uncontrolled usage. |
| `onChange` | `(isSelected: boolean) => void` | `—` | Handler called whenever the toggle state flips. |
| `isDisabled` / `disabled` | `boolean` | `false` | Disables pressing and keyboard interaction. |
| `id` | `Key` | `—` | Item identifier when nested inside `ToggleButtonGroup`. |

### ToggleButtonGroup

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `selectionMode` | `'single' \| 'multiple'` | `'single'` | Controls whether one or multiple child buttons stay active. |
| `disallowEmptySelection` | `boolean` | `false` | Prevents unselecting the final active item (ideal for theme switches). |
| `selectedKeys` / `defaultSelectedKeys` | `Iterable<Key>` | `—` | Controlled or initial selected button `id` keys. |
| `onSelectionChange` | `(keys: Set<Key>) => void` | `—` | Callback fired when active selection keys change. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Stack axis for grouped toggle buttons. |
| `isDisabled` | `boolean` | `false` | Disables all toggle buttons inside the group. |

### Segmented Single & Multi Selection

Compose compact segmented switchers using `ToggleButtonGroup`.

    </ToggleButtonGroup>

    <ToggleButtonGroup
      aria-label="Formatting toggles"
      selectionMode="multiple"
      defaultSelectedKeys={['bold']}

      <ToggleButton id="bold" size="sm">Bold</ToggleButton>
      <ToggleButton id="italic" size="sm">Italic</ToggleButton>
      <ToggleButton id="mono" size="sm">Mono</ToggleButton>
    </ToggleButtonGroup>
  </div>
</ComponentPreview>

```tsx
import { ToggleButton, ToggleButtonGroup } from '@pact-design/react'

<ToggleButtonGroup
  aria-label="Preview view mode"
  selectionMode="single"
  disallowEmptySelection
  defaultSelectedKeys={['grid']}
>
  <ToggleButton id="list" size="sm" variant="primary">List</ToggleButton>
  <ToggleButton id="grid" size="sm" variant="primary">Grid</ToggleButton>
  <ToggleButton id="table" size="sm" variant="primary">Table</ToggleButton>
</ToggleButtonGroup>
```
