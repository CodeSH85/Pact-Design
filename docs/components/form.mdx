## 何時使用

- 需要收集、驗證並送出多組使用者輸入資料時使用。
- 當表單內容較長時，使用 `FormSection` 將相關欄位歸納為具標題與說明的邏輯分區，減輕填寫壓力。
- 使用 `FormActions` 統一排列送出、取消或重設按鈕，保持跨頁面一致的操作位置。

## 使用範例

### 緊湊間距與左右對齊操作列

在側邊屬性面板或對話框內，可將 `Form` 的 `gap` 設為 `sm` 並搭配 `FormActions` 的 `align="between"`，將輔助測試按鈕與主要套用按鈕分置兩側。

<ComponentPreview align="stretch">

    <Checkbox defaultChecked label="啟用提交訊息格式檢查" />
    <FormActions align="between">
      <Button type="button" variant="subtle" size="sm">測試連線</Button>
      <Button type="submit" variant="primary" size="sm">套用設定</Button>
    </FormActions>
  </Form>
</ComponentPreview>

## API 參考

### Form

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `gap` | `'sm' \| 'md' \| 'lg'` | `'md'` | 表單分區與欄位之間的垂直間距大小。 |
| `validationErrors` | `Record<string, string \| string[]>` | `—` | 依欄位 `name` 對應的外部或伺服器端驗證錯誤訊息。 |
| `validationBehavior` | `'native' \| 'aria'` | `'native'` | 選擇原生瀏覽器表單驗證或僅透過無障礙屬性回報。 |
| `onSubmit` | `(e: FormEvent<HTMLFormElement>) => void` | `—` | 表單送出時觸發的回呼函式。 |
| `className` | `string` | `—` | 額外套用的自訂樣式類別。 |

### FormSection

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `title` | `ReactNode` | `—` | 分區標題文字。 |
| `description` | `ReactNode` | `—` | 顯示於標題下方的補充說明。 |
| `className` | `string` | `—` | 額外套用的自訂樣式類別。 |

### FormActions

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `align` | `'start' \| 'center' \| 'end' \| 'between'` | `'end'` | 底部操作按鈕群組的水平對齊方式。 |
| `className` | `string` | `—` | 額外套用的自訂樣式類別。 |
