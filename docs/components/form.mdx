## API Reference

Built on React Aria `Form`. Exports `Form`, `FormSection`, `FormActions`, `FormContext`, and `formVariants`.

### Form

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `gap` | `'sm' \| 'md' \| 'lg'` | `'md'` | Vertical spacing scale between sections and fields. |
| `validationErrors` | `Record<string, string \| string[]>` | `—` | Server/external validation errors keyed by field `name`. |
| `validationBehavior` | `'native' \| 'aria'` | `'native'` | Controls native HTML vs ARIA constraint reporting. |
| `onSubmit` | `(e: FormEvent<HTMLFormElement>) => void` | `—` | Form submission callback. |
| `className` | `string` | `—` | Additional CSS classes merged with the form stack. |

### FormSection

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `ReactNode` | `—` | Section heading (`h3`). |
| `description` | `ReactNode` | `—` | Supporting caption displayed under `title`. |
| `className` | `string` | `—` | Additional CSS classes for the section block. |

### FormActions

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `align` | `'start' \| 'center' \| 'end' \| 'between'` | `'end'` | Horizontal alignment for action buttons. |
| `className` | `string` | `—` | Additional CSS classes for the footer action bar. |

Combine `gap="sm"` on `Form` with `align="between"` on `FormActions` for compact dialogs or property inspectors.
