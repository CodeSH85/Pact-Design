## 何時使用

- 當工具列、表格列或卡片右上角有超過三個操作按鈕時，將次要操作收納進下拉選單，保持畫面清爽。
- 適合承載「立即執行的命令」，例如複製、匯出、重新命名、刪除等，並可顯示鍵盤快捷鍵提升熟練使用者的效率。
- 若操作目的是讓使用者在表單中挑選並保留某個值，請改用 **Select 下拉選單**。

## 使用範例

### 組合式子元件

透過組合 `Menu`、`MenuPopover`、`MenuList`、`MenuSection`、`MenuHeader`、`MenuItem` 與 `MenuSeparator`，可自由搭配任意觸發按鈕並控制展開對齊位置。

<ComponentPreview>
  <Menu trigger={<Button variant="primary">Custom Trigger</Button>}>
    <MenuPopover placement="bottom end">
      <MenuList>
        <MenuSection>
          <MenuHeader>Density</MenuHeader>
          <MenuItem id="compact" shortcut="⌘1">Compact</MenuItem>
          <MenuItem id="default" shortcut="⌘2">Default</MenuItem>
        </MenuSection>
        <MenuSeparator />
        <MenuItem id="delete" tone="danger">Clear Cache</MenuItem>
      </MenuList>
    </MenuPopover>
  </Menu>
</ComponentPreview>

```tsx
import {
  Button,
  Menu,
  MenuHeader,
  MenuItem,
  MenuList,
  MenuPopover,
  MenuSection,
  MenuSeparator
} from '@pact-design/react'

<Menu trigger={<Button variant="primary">Custom Trigger</Button>}>
  <MenuPopover placement="bottom end">
    <MenuList>
      <MenuSection>
        <MenuHeader>Density</MenuHeader>
        <MenuItem id="compact" shortcut="⌘1">Compact</MenuItem>
        <MenuItem id="default" shortcut="⌘2">Default</MenuItem>
      </MenuSection>
      <MenuSeparator />
      <MenuItem id="delete" tone="danger">Clear Cache</MenuItem>
    </MenuList>
  </MenuPopover>
</Menu>
```

### 圖示與單選勾選狀態

透過 `MenuItem` 的 `icon` 屬性加入前置圖示，並在 `MenuList` 設定 `selectionMode="single"` 與 `selectedKeys`，即可自動於已選取項目右側顯示勾選圖示。

<ComponentPreview>
  <Menu
    trigger={(
      <Button variant="secondary" size="sm" icon aria-label="切換主題">
        <RiSunLine />
      </Button>
    )}
  >
    <MenuPopover placement="bottom end">
      <MenuList aria-label="主題模式" selectionMode="single" defaultSelectedKeys={['system']}>
        <MenuItem id="light" icon={<RiSunLine />}>淺色 Light</MenuItem>
        <MenuItem id="dark" icon={<RiMoonLine />}>深色 Dark</MenuItem>
        <MenuItem id="system" icon={<RiComputerLine />}>跟隨系統 System</MenuItem>
      </MenuList>
    </MenuPopover>
  </Menu>
</ComponentPreview>

```tsx
import { Button, Menu, MenuItem, MenuList, MenuPopover } from '@pact-design/react'
import { RiComputerLine, RiMoonLine, RiSunLine } from '@remixicon/react'

<Menu
  trigger={(
    <Button variant="secondary" size="sm" icon aria-label="切換主題">
      <RiSunLine />
    </Button>
  )}

  <MenuPopover placement="bottom end">
    <MenuList aria-label="主題模式" selectionMode="single" defaultSelectedKeys={['system']}>
      <MenuItem id="light" icon={<RiSunLine />}>淺色 Light</MenuItem>
      <MenuItem id="dark" icon={<RiMoonLine />}>深色 Dark</MenuItem>
      <MenuItem id="system" icon={<RiComputerLine />}>跟隨系統 System</MenuItem>
    </MenuList>
  </MenuPopover>
</Menu>
```

## API 參考

### Menu

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `items` | `MenuItemData[]` | `—` | 聲明式選單資料陣列，支援一般項目、分組與分隔線。 |
| `trigger` | `ReactNode` | 內建次要按鈕 | 取代預設按鈕的自訂觸發元件。 |
| `triggerLabel` | `string` | `'Actions'` | 未傳入 `trigger` 與子元件時，內建按鈕顯示的文字。 |
| `placement` | `PopoverProps['placement']` | `'bottom start'` | 選單相對於觸發按鈕的展開對齊方向。 |
| `offset` | `number` | `6` | 選單與觸發按鈕之間的像素間距。 |
| `triggerType` | `'press' \| 'longPress'` | `'press'` | 開啟選單的互動觸發方式。 |

### MenuItem

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `id` | `Key` | `—` | 項目識別鍵，搭配 `MenuList` 的 `selectionMode` 與 `selectedKeys` 使用。 |
| `icon` | `ReactNode` | `—` | 顯示於項目文字左側的前置圖示（自動縮放至 `16px`）。 |
| `tone` | `'default' \| 'danger'` | `'default'` | 設為 `danger` 時以危險語意色提示高風險操作。 |
| `shortcut` | `string` | `—` | 顯示於項目右側的鍵盤快捷鍵提示。 |
| `isDisabled` | `boolean` | `false` | 是否停用該選單項目。 |
| `onAction` | `() => void` | `—` | 使用者點選該項目時觸發的回呼函式。 |
