## API Reference

Built on React Aria `DatePicker`, composing `DateInput`, `FieldButton`, `PopoverContent`, `Dialog`, and `Calendar`.

### DatePicker

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | Accessible label rendered above the picker input. |
| `description` | `ReactNode` | `—` | Helper caption displayed underneath. |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | Validation error text when invalid. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`) for `FieldGroup`. |
| `value` / `defaultValue` | `DateValue` | `—` | Controlled or initial selected date. |
| `onChange` | `(value: DateValue \| null) => void` | `—` | Callback fired when date changes from input or calendar. |
| `minValue` / `maxValue` | `DateValue` | `—` | Restricts selectable calendar dates. |
| `isDisabled` | `boolean` | `false` | Disables text segments and calendar trigger button. |
| `dateInputProps` | `DateInputProps` | `—` | Props forwarded to `DateInput`. |
| `popoverProps` | `DatePickerPopoverProps` | `—` | Props forwarded to `PopoverContent` (default placement `'bottom start'`). |
| `calendarProps` | `Partial<CalendarProps<T>>` | `—` | Props forwarded to the embedded `Calendar`. |

### Bounded Selection & Disabled

Constrain selectable dates or disable the entire control.

      maxValue={parseDate('2026-11-25')}
