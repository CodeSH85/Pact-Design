## 何時使用

- 適合需要對照星期、瀏覽當月或近期排程的表單情境，例如專案截止日、預約排程或報表查詢日期。
- 同時保留鍵盤分段輸入與滑鼠點選月曆兩種操作路徑，兼顧高頻操作效率與視覺直覺。
- 若只需純鍵盤快速輸入已知歷史日期，可使用更輕量的 **DateField 日期欄位**；若需將月曆直接常駐於畫面中，請改用 **Calendar 行事曆**。

## 尺寸

支援五階高度比例，可與工具列或表單內其他輸入控制項保持齊平。

## 可選範圍與停用狀態

透過 `minValue` 與 `maxValue` 限制可點選的日期區間，超出範圍的日期會自動呈現不可選取狀態；透過 `isDisabled` 可停用整個選擇器。

<ComponentPreview align="stretch">

      defaultValue={parseDate('2026-11-18')}
      minValue={parseDate('2026-11-10')}
      maxValue={parseDate('2026-11-25')}
    />
    <DatePicker
      label="Disabled"
      isDisabled
      defaultValue={parseDate('2026-11-18')}
    />
  </div>
</ComponentPreview>

```tsx

  defaultValue={parseDate('2026-11-18')}
  minValue={parseDate('2026-11-10')}
  maxValue={parseDate('2026-11-25')}
/>

<DatePicker
  label="Disabled"
  isDisabled
  defaultValue={parseDate('2026-11-18')}
/>
```

## API 參考

### DatePicker

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於選擇器上方的欄位標籤。 |
| `description` | `ReactNode` | `—` | 顯示於欄位下方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 驗證失敗時顯示的錯誤提示。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 欄位高度與內距大小。 |
| `value` / `defaultValue` | `DateValue` | `—` | 受控或預設選取的日期。 |
| `onChange` | `(value: DateValue \| null) => void` | `—` | 透過輸入或月曆變更日期時觸發的回呼函式。 |
| `minValue` / `maxValue` | `DateValue` | `—` | 限制可選取的最早與最晚日期。 |
| `isDisabled` | `boolean` | `false` | 是否停用輸入與展開月曆。 |
| `dateInputProps` | `DateInputProps` | `—` | 傳遞至內層日期輸入列的額外屬性。 |
| `popoverProps` | `DatePickerPopoverProps` | `—` | 傳遞至浮動視窗的額外屬性，預設對齊於左下方。 |
| `calendarProps` | `Partial<CalendarProps<T>>` | `—` | 傳遞至內嵌月曆的額外屬性。 |
