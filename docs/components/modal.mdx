## 何時使用

- 適合高重要性確認、無法復原的刪除警告，或需要使用者暫停當前頁面流程專心填寫的精簡表單。
- 開啟時會自動加上半透明背景遮罩並限制焦點在視窗範圍內，避免背景頁面被誤觸。
- 若內容篇幅較長或希望保留部分主畫面脈絡以便對照，建議改用 **Sheet 側邊抽屜**；若僅為輕量補充說明，建議改用 **Popover 浮動視窗**。

## 寬度尺寸

提供從精簡 `sm` 到全螢幕 `full` 五種寬度預設，依內容複雜度自由選擇。

## 禁止點擊背景關閉

面對必須明確表態的操作流程，可透過 `ModalTrigger` 與 `ModalContent` 搭配 `isDismissable={false}`，防止使用者誤觸遮罩而關閉視窗。

<ComponentPreview>
  <ModalTrigger>
    <Button variant="subtle">Non-Dismissable</Button>
    <ModalContent size="sm" isDismissable={false}>
      <ModalDialog>
        <ModalHeader
          title="Save Changes?"
          description="Backdrop clicks are disabled; choose an explicit action below."
          showCloseButton={false}
        />
        <ModalFooter>
          <Button variant="ghost" size="sm" slot="close">Discard</Button>
          <Button variant="primary" size="sm" slot="close">Save</Button>
        </ModalFooter>
      </ModalDialog>
    </ModalContent>
  </ModalTrigger>
</ComponentPreview>

```tsx
import {
  Button,
  ModalContent,
  ModalDialog,
  ModalFooter,
  ModalHeader,
  ModalTrigger
} from '@pact-design/react'

<ModalTrigger>
  <Button variant="subtle">Non-Dismissable</Button>
  <ModalContent size="sm" isDismissable={false}>
    <ModalDialog>
      <ModalHeader
        title="Save Changes?"
        description="Backdrop clicks are disabled."
        showCloseButton={false}
      />
      <ModalFooter>
        <Button variant="ghost" size="sm" slot="close">Discard</Button>
        <Button variant="primary" size="sm" slot="close">Save</Button>
      </ModalFooter>
    </ModalDialog>
  </ModalContent>
</ModalTrigger>
```

## API 參考

### Modal

傳入 `trigger` 時會自動組合觸發按鈕、背景遮罩、標題區與底部操作列。

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `trigger` | `ReactNode` | `—` | 點擊後開啟互動視窗的按鈕或元件。 |
| `title` | `ReactNode` | `—` | 視窗頂部的主標題文字。 |
| `description` | `ReactNode` | `—` | 顯示於標題下方的輔助說明。 |
| `footer` | `ReactNode` | `—` | 顯示於底部的操作按鈕區域。 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | 視窗面板的最大寬度等級。 |
| `isDismissable` | `boolean` | `true` | 是否允許點擊外部遮罩關閉視窗。 |
| `isOpen` / `defaultOpen` | `boolean` | `—` | 受控或預設的開啟狀態。 |
| `onOpenChange` | `(isOpen: boolean) => void` | `—` | 視窗開啟或關閉時觸發的回呼函式。 |

### ModalContent

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | 視窗面板的最大寬度等級。 |
| `isDismissable` | `boolean` | `true` | 是否允許點擊外部遮罩關閉視窗。 |
| `overlayClassName` | `string` | `—` | 額外套用於全螢幕遮罩層的自訂樣式類別。 |
| `className` | `string` | `—` | 額外套用於視窗面板的自訂樣式類別。 |
