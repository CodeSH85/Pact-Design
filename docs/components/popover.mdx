## 何時使用

- 適合呈現與特定按鈕或項目直接相關的補充資訊、小型表單、篩選條件或快速檢視面板，無須遮擋整個畫面。
- 浮動視窗會自動偵測螢幕邊界並調整展開位置，避免內容被視窗邊緣裁切。
- 若內容僅為一組純文字操作命令，建議改用 **Menu 選單**；若需要使用者暫停當前工作並完成重要確認或複雜表單，請改用 **Modal 互動視窗** 或 **Sheet 側邊抽屜**。

## 指向箭頭與展開方向

透過 `contentProps` 設定 `placement`、`offset` 與 `showArrow`，讓浮動視窗明確指向其觸發來源。

<ComponentPreview>
  <Popover
    trigger={<Button variant="secondary" size="sm">Top + Arrow</Button>}
    contentProps={{ placement: 'top', showArrow: true, offset: 10 }}
  >
    <div className="p-xs text-caption-md text-on-surface">placement="top" showArrow</div>
  </Popover>
  <Popover
    trigger={<Button variant="secondary" size="sm">Right</Button>}
    contentProps={{ placement: 'right', offset: 8 }}
  >
    <div className="p-xs text-caption-md text-on-surface">placement="right"</div>
  </Popover>
</ComponentPreview>

```tsx
<Popover
  trigger={<Button variant="secondary">Top + Arrow</Button>}
  contentProps={{ placement: 'top', showArrow: true, offset: 10 }}
>
  <div className="p-xs">placement="top" showArrow</div>
</Popover>
```

## API 參考

### Popover

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `trigger` | `ReactNode` | `—` | 點擊後開啟浮動視窗的觸發元件；省略時可自行傳入組合子元件。 |
| `contentProps` | `Omit<PopoverContentProps, 'children'>` | `—` | 傳遞至浮動容器的定位、間距與箭頭顯示設定。 |
| `dialogProps` | `PopoverDialogProps` | `—` | 傳遞至內層對話框容器的額外屬性。 |
| `isOpen` / `defaultOpen` | `boolean` | `—` | 受控或預設的開啟狀態。 |
| `onOpenChange` | `(isOpen: boolean) => void` | `—` | 開啟或關閉狀態變化時觸發的回呼函式。 |

### PopoverContent

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `placement` | `PopoverProps['placement']` | `'bottom'` | 偏好的展開方向，例如 `'top'`、`'bottom start'`、`'right'`。 |
| `offset` | `number` | `6` | 浮動視窗與觸發元件之間的像素距離。 |
| `showArrow` | `boolean` | `false` | 是否顯示指向觸發元件的箭頭。 |
| `className` | `string \| ((props) => string)` | `—` | 額外套用於浮動容器的自訂樣式類別。 |
