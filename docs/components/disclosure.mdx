## 何時使用

- 適合收納補充說明、常見問題解答、進階表單設定或側邊導覽分組，讓使用者在需要時再展開檢視。
- 提供兩種外觀樣式：`bordered` 適合獨立呈現於內容區的卡片區塊；`ghost` 則去除外框改以底線區隔，非常適合側邊欄或高密度屬性面板。
- 若有多組折疊面板需要成群排列並協調展開行為，建議搭配 **DisclosureGroup 折疊面板群組**。

## 使用範例

### 視覺樣式

比較帶外框的 `bordered` 卡片樣式與輕量底線的 `ghost` 樣式。

<ComponentPreview align="stretch">
  <div className="flex flex-col gap-md">
    <Disclosure variant="bordered" title="Bordered" defaultExpanded>
      Standalone card container with full border and subtle corner radius.
    </Disclosure>
    <Disclosure variant="ghost" title="Ghost">
      Borderless row with a bottom divider, suited for sidebars and panels.
    </Disclosure>
  </div>
</ComponentPreview>

```tsx
<Disclosure variant="bordered" title="Bordered" defaultExpanded>
  Standalone card container with full border and subtle corner radius.
</Disclosure>
<Disclosure variant="ghost" title="Ghost">
  Borderless row with a bottom divider, suited for sidebars and panels.
</Disclosure>
```

### 自訂標頭與內容結構

省略 `title` 屬性即可自行組合 `DisclosureHeader` 與 `DisclosurePanel`，彈性調整標頭內容與面板背景樣式。

<ComponentPreview align="stretch">
  <Disclosure>
    <DisclosureHeader>Custom Header</DisclosureHeader>
    <DisclosurePanel className="bg-layer-2">
      Custom panel styled independently via <code>DisclosurePanel</code>.
    </DisclosurePanel>
  </Disclosure>
</ComponentPreview>

```tsx
import { Disclosure, DisclosureHeader, DisclosurePanel } from '@pact-design/react'

<Disclosure>
  <DisclosureHeader>Custom Header</DisclosureHeader>
  <DisclosurePanel className="bg-layer-2">
    Custom panel styled independently.
  </DisclosurePanel>
</Disclosure>
```

## API 參考

### Disclosure

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `title` | `ReactNode` | `—` | 傳入標題時會自動渲染標頭並將子內容包入 `DisclosurePanel`。 |
| `variant` | `'bordered' \| 'ghost'` | `'bordered'` | 外觀樣式，位於 `DisclosureGroup` 內時會自動繼承群組風格。 |
| `isExpanded` / `defaultExpanded` | `boolean` | `false` | 受控或預設的展開狀態。 |
| `onExpandedChange` | `(isExpanded: boolean) => void` | `—` | 展開或收合狀態改變時觸發的回呼函式。 |
| `isDisabled` | `boolean` | `false` | 是否停用展開與收合操作。 |
| `panelProps` | `DisclosurePanelProps` | `—` | 使用 `title` 簡寫時傳遞至內層 `DisclosurePanel` 的額外屬性。 |
| `className` | `string` | `—` | 額外套用於外層容器的自訂樣式類別。 |

### 子元件

- **`DisclosureHeader`**：包含標題文字與旋轉展開箭頭的觸發標頭。
- **`DisclosurePanel`**：可收合的內容面板區域。
