## API Reference

Built on React Aria `Disclosure`, `DisclosurePanel`, `Heading`, and `Button` (`slot="trigger"`). Exports `Disclosure`, `DisclosureHeader`, and `DisclosurePanel`.

### Disclosure

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `ReactNode` | `—` | When provided, renders `DisclosureHeader` and wraps `children` in `DisclosurePanel` automatically. |
| `variant` | `'bordered' \| 'ghost'` | `'bordered'` (inherits from `DisclosureGroup` when grouped) | Bordered card or bottom-divider ghost style. |
| `isExpanded` / `defaultExpanded` | `boolean` | `false` | Controlled or initial expanded state. |
| `onExpandedChange` | `(isExpanded: boolean) => void` | `—` | Callback fired when expansion state toggles. |
| `isDisabled` | `boolean` | `false` | Disables toggling the panel. |
| `panelProps` | `DisclosurePanelProps` | `—` | Props forwarded to `DisclosurePanel` when `title` shorthand is used. |
| `className` | `string` | `—` | Optional CSS classes for the root disclosure container. |

### Parts

- **`DisclosureHeader`**: Wraps `AriaHeading` + `AriaButton` (`slot="trigger"`) with rotating `RiArrowRightSLine` chevron.
- **`DisclosurePanel`**: Collapsible region hidden via `aria-hidden:hidden`.

### Custom Panel Composition

Omit `title` and compose `DisclosureHeader` + `DisclosurePanel` directly for full control over header markup and panel padding.

    </DisclosurePanel>
  </Disclosure>
</ComponentPreview>
