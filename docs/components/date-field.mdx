## API Reference

Built on React Aria `DateField`, `DateInput`, and `DateSegment`. Exports `DateField`, `DateInput`, `DateSegment`, and type `DateValue`.

### DateField

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | Field label above the segmented date input. |
| `description` | `ReactNode` | `—` | Supporting text beneath the input. |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | Error text shown when the entered date fails validation. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`) applied to `FieldGroup`. |
| `value` / `defaultValue` | `DateValue` | `—` | Controlled or initial date value. |
| `onChange` | `(value: DateValue \| null) => void` | `—` | Fired when the date value changes. |
| `minValue` / `maxValue` | `DateValue` | `—` | Valid selectable date range bounds. |
| `granularity` | `'day' \| 'hour' \| 'minute' \| 'second'` | `'day'` | Smallest editable segment precision. |
| `isDisabled` | `boolean` | `false` | Disables segment editing. |
| `isReadOnly` | `boolean` | `false` | Prevents user edits while remaining focusable. |
| `dateInputProps` | `DateInputProps` | `—` | Props forwarded to the default `DateInput`. |

### Parts

- **`DateInput`**: Flex row rendering `DateSegment` items inside `FieldGroup`.
- **`DateSegment`**: Individual interactive year, month, day, or literal segment formatted with `tabular-nums font-mono`.
