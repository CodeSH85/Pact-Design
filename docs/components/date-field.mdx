## 何時使用

- 當使用者已經明確知道目標日期，例如出生年月日、發票日期或歷史紀錄時間，直接透過鍵盤逐段輸入比翻找月曆更快速。
- 每個日期區段皆可獨立聚焦並以方向鍵增減數值，避免格式輸入錯誤。
- 若使用者需要對照星期幾或瀏覽整月排程，建議改用搭配月曆彈窗的 **DatePicker 日期選擇器**。

## 使用範例

### 尺寸

提供五種高度規格，方便與周圍表單控制項對齊。

<ComponentPreview align="stretch">
  <div className="grid grid-cols-1 md:grid-cols-2 gap-md">
    <DateField label="緊湊尺寸" size="sm" defaultValue={parseDate('2026-11-18')} />
    <DateField label="舒適尺寸" size="lg" defaultValue={parseDate('2026-11-18')} />
  </div>
</ComponentPreview>

```tsx
<DateField label="緊湊尺寸" size="sm" defaultValue={parseDate('2026-11-18')} />
<DateField label="舒適尺寸" size="lg" defaultValue={parseDate('2026-11-18')} />
```

### 時間精度與停用狀態

可透過 `granularity` 擴充至小時、分鐘或秒數輸入，或透過 `isDisabled` 鎖定欄位內容。

<ComponentPreview align="stretch">
  <div className="grid grid-cols-1 md:grid-cols-2 gap-md">
    <DateField label="精確至小時" granularity="hour" />
    <DateField label="停用狀態" isDisabled defaultValue={parseDate('2026-11-18')} />
  </div>
</ComponentPreview>

```tsx
<DateField label="精確至小時" granularity="hour" />
<DateField label="停用狀態" isDisabled defaultValue={parseDate('2026-11-18')} />
```

## API 參考

### DateField

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於欄位上方的標籤文字。 |
| `description` | `ReactNode` | `—` | 顯示於欄位下方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 日期驗證失敗時顯示的錯誤提示。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 欄位高度與內距大小。 |
| `value` / `defaultValue` | `DateValue` | `—` | 受控或預設的日期值。 |
| `onChange` | `(value: DateValue \| null) => void` | `—` | 日期值改變時觸發的回呼函式。 |
| `minValue` / `maxValue` | `DateValue` | `—` | 允許輸入的最早與最晚日期邊界。 |
| `granularity` | `'day' \| 'hour' \| 'minute' \| 'second'` | `'day'` | 可編輯的最小時間單位精度。 |
| `isDisabled` | `boolean` | `false` | 是否停用欄位編輯。 |
| `isReadOnly` | `boolean` | `false` | 是否設為唯讀，保留聚焦能力但禁止修改。 |
| `dateInputProps` | `DateInputProps` | `—` | 傳遞至內層 `DateInput` 的額外屬性。 |

### 子元件

- **`DateInput`**：承載各日期區段的外層輸入列容器。
- **`DateSegment`**：單一可聚焦與編輯的年、月、日或分隔符號區段。
