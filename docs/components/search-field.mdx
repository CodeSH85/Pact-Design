## API Reference

Built on React Aria `SearchField`, composing `Label`, `FieldGroup`, `Input`, `FieldButton`, `FieldDescription`, and `FieldError`. Automatically displays an embedded clear button (`RiCloseLine`) whenever `data-[empty]` is absent.

### SearchField

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | Accessible label rendered above the search box. |
| `description` | `ReactNode` | `—` | Supporting caption displayed below the input. |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | Validation message shown when invalid. |
| `placeholder` | `string` | `'Search...'` | Input placeholder hint. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`) applied to `FieldGroup`. |
| `value` / `defaultValue` | `string` | `—` | Controlled or initial search query string. |
| `onChange` | `(value: string) => void` | `—` | Fired whenever query text changes. |
| `onSubmit` | `(value: string) => void` | `—` | Fired when Enter is pressed inside the input. |
| `onClear` | `() => void` | `—` | Fired when the clear button or Escape clears the input. |
| `isDisabled` | `boolean` | `false` | Disables text input and clear actions. |
