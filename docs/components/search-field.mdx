## 何時使用

- 適合置於資料表上方、側邊欄頂部或工具列中，協助使用者快速查找與篩選大量內容。
- 使用者開始輸入文字後，欄位右側會自動出現清除按鈕，也可直接按下 `Escape` 鍵一鍵清空搜尋條件。
- 若需要邊輸入邊從下拉清單挑選特定項目，建議改用 **Autocomplete 自動完成** 或 **ComboBox 組合方塊**。

## 尺寸

支援五種高度規格，可從工具列專用的超緊湊 `xs` 調整至頁面篩選列適用的舒適 `lg`。

## 預設值與停用狀態

當搜尋欄位已有內容時會自動顯示右側清除按鈕；設為 `isDisabled` 時則鎖定編輯與清除操作。

<ComponentPreview align="stretch">
  <div className="grid grid-cols-1 md:grid-cols-2 gap-md">
    <SearchField label="Default Value" defaultValue="Button" />
    <SearchField label="Disabled" isDisabled defaultValue="Locked query" />
  </div>
</ComponentPreview>

```tsx

<SearchField label="Disabled" isDisabled defaultValue="Locked query" />
```

## API 參考

### SearchField

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `—` | 顯示於搜尋欄位上方的標籤文字。 |
| `description` | `ReactNode` | `—` | 顯示於欄位下方的輔助說明。 |
| `errorMessage` | `ReactNode \| ((validation) => ReactNode)` | `—` | 欄位驗證失敗時顯示的錯誤提示。 |
| `placeholder` | `string` | `'Search...'` | 輸入框空白時的提示文字。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 搜尋欄位的高度與內距大小。 |
| `value` / `defaultValue` | `string` | `—` | 受控或預設的搜尋字串。 |
| `onChange` | `(value: string) => void` | `—` | 搜尋內容改變時觸發的回呼函式。 |
| `onSubmit` | `(value: string) => void` | `—` | 在欄位中按下 `Enter` 時觸發的回呼函式。 |
| `onClear` | `() => void` | `—` | 點擊清除按鈕或按下 `Escape` 清空內容時觸發。 |
| `isDisabled` | `boolean` | `false` | 是否停用搜尋輸入與清除按鈕。 |
