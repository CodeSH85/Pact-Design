## 何時使用

- 一般情境建議直接使用已整合遮罩與動畫的高階元件 **Modal 互動視窗** 或 **Sheet 側邊抽屜**。
- 當你需要客製化覆蓋層的內距、自訂標頭排版，或將對話框結構嵌入自訂彈出容器中時，可透過 `Dialog` 系列子元件靈活組裝。
- 內建焦點管理與無障礙語意關聯，將按鈕加上 `slot="close"` 即可自動綁定關閉對話框行為。

## 隱藏右上角關閉按鈕

在要求使用者必須明確點選底部按鈕做出決定的確認流程中，可將 `showCloseButton` 設為 `false` 並搭配不可點擊背景關閉的設定。

## API 參考

### 組成元件

- **`DialogTrigger`**：串聯觸發按鈕與對應覆蓋層容器的控制元件。
- **`Dialog`**：負責焦點管理與無障礙標題關聯的對話框主容器。
- **`DialogHeader`**：呈現標題、副標說明與右上角關閉按鈕的標頭區。
- **`DialogBody`**：可獨立垂直捲動的主體內容區。
- **`DialogFooter`**：靠右對齊的底部操作按鈕區。
- **`DialogCloseButton`**：自動觸發關閉對話框的圖示按鈕。

### DialogHeader

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `title` | `ReactNode` | `—` | 對話框主標題。 |
| `description` | `ReactNode` | `—` | 顯示於主標題下方的補充說明文字。 |
| `showCloseButton` | `boolean` | `true` | 是否於右上角顯示關閉按鈕。 |
| `className` | `string` | `—` | 額外套用於標頭容器的自訂樣式類別。 |

### DialogCloseButton

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `aria-label` | `string` | `'Close'` | 供螢幕閱讀器朗讀的按鈕名稱。 |
| `className` | `string` | `—` | 額外套用於關閉按鈕的自訂樣式類別。 |
