## API Reference

Built on React Aria `SheetTrigger`, `SheetOverlay`, `SheetBackdrop`, `Sheet`, and `SheetContent`. Exports `Sheet`, `SheetTrigger`, `SheetOverlay`, `SheetBackdrop`, `SheetPanel`, `SheetContent`, `SheetHeader`, `SheetBody`, and `SheetFooter`.

### Sheet

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `trigger` | `ReactNode` | `—` | Pressable element that toggles opening the sheet. |
| `title` | `ReactNode` | `—` | Header heading rendered inside `SheetHeader`. |
| `description` | `ReactNode` | `—` | Subtitle rendered underneath `title`. |
| `footer` | `ReactNode` | `—` | Footer controls rendered inside `SheetFooter`. |
| `position` | `'right' \| 'left' \| 'top' \| 'bottom' \| 'start' \| 'end' \| 'center'` | `'right'` | Viewport anchor edge or centered presentation. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | Drawer max-width (horizontal edges) or max-height (top/bottom edges). |
| `isDismissable` | `boolean` | `true` | Allows dismissing via backdrop click or swipe gesture. |
| `preventDismissal` | `boolean` | `!isDismissable` | Explicitly blocks user swipe/backdrop dismissal. |
| `swipeDirection` | `'left' \| 'right' \| 'up' \| 'down' \| 'none'` | Inferred from `position` | Overrides swipe-to-dismiss direction. |
| `snapPoints` | `Array<number \| string>` | `—` | Scroll-snap points supported by React Aria `SheetOverlay`. |
| `isOpen` / `defaultOpen` | `boolean` | `—` | Controlled or initial open state. |
| `onOpenChange` | `(isOpen: boolean) => void` | `—` | Handler called when sheet open state changes. |

### Composable Subcomponents

Use `SheetTrigger`, `SheetOverlay`, `SheetPanel`, `SheetContent`, `SheetHeader`, `SheetBody`, and `SheetFooter` for custom layout chrome.

<ComponentPreview>
  <SheetTrigger>
    <Button variant="subtle">Custom Sheet Composition</Button>
    <SheetOverlay position="right">
      <SheetPanel position="right" size="md">
        <SheetContent>
          <SheetHeader title="Custom Layout" description="Composed directly with Sheet parts." />
          <SheetBody>
            <p className="text-body-sm text-on-surface m-0">
              Directly control panel, overlay, and backdrop classes per slot.
            </p>
          </SheetBody>
          <SheetFooter>
            <Button variant="primary" size="sm" slot="close">Close Drawer</Button>
          </SheetFooter>
        </SheetContent>
      </SheetPanel>
    </SheetOverlay>
  </SheetTrigger>
</ComponentPreview>

```tsx
import {
  Button,
  SheetBody,
  SheetContent,
  SheetFooter,
  SheetHeader,
  SheetOverlay,
  SheetPanel,
  SheetTrigger
} from '@pact-design/react'

<SheetTrigger>
  <Button variant="subtle">Custom Sheet Composition</Button>
  <SheetOverlay position="right">
    <SheetPanel position="right" size="md">
      <SheetContent>
        <SheetHeader title="Custom Layout" />
        <SheetBody>...</SheetBody>
        <SheetFooter>
          <Button variant="primary" size="sm" slot="close">Close Drawer</Button>
        </SheetFooter>
      </SheetContent>
    </SheetPanel>
  </SheetOverlay>
</SheetTrigger>
```
