## 何時使用

- 適合在不離開主清單或資料表的情況下，從右側滑出詳細檢視器、進階篩選器或較長的新增與編輯表單。
- 亦可用於左側滑出的行動版導覽選單，或底部滑出的快速操作面板。
- 若任務屬於高度聚焦的簡短二次確認，請改用 **Modal 互動視窗**。

## 使用範例

透過 `position` 指定面板從左側、右側、頂部、底部或畫面中央滑出。

### 組合式子元件

若需要更細緻的結構控制，可直接組合 `SheetTrigger`、`SheetOverlay`、`SheetPanel`、`SheetContent`、`SheetHeader`、`SheetBody` 與 `SheetFooter`。

<ComponentPreview>
  <SheetTrigger>
    <Button variant="subtle">Custom Composition</Button>
    <SheetOverlay position="right">
      <SheetPanel position="right" size="md">
        <SheetContent>
          <SheetHeader title="Custom Layout" description="Composed directly with Sheet parts." />
          <SheetBody>
            <p className="text-body-sm text-on-surface m-0">
              Control panel, overlay, and footer slots independently.
            </p>
          </SheetBody>
          <SheetFooter>
            <Button variant="primary" size="sm" slot="close">Close</Button>
          </SheetFooter>
        </SheetContent>
      </SheetPanel>
    </SheetOverlay>
  </SheetTrigger>
</ComponentPreview>

```tsx
import {
  Button,
  SheetBody,
  SheetContent,
  SheetFooter,
  SheetHeader,
  SheetOverlay,
  SheetPanel,
  SheetTrigger
} from '@pact-design/react'

<SheetTrigger>
  <Button variant="subtle">Custom Composition</Button>
  <SheetOverlay position="right">
    <SheetPanel position="right" size="md">
      <SheetContent>
        <SheetHeader title="Custom Layout" />
        <SheetBody>...</SheetBody>
        <SheetFooter>
          <Button variant="primary" size="sm" slot="close">Close</Button>
        </SheetFooter>
      </SheetContent>
    </SheetPanel>
  </SheetOverlay>
</SheetTrigger>
```

## API 參考

### Sheet

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `trigger` | `ReactNode` | `—` | 點擊後開啟側邊抽屜的觸發元件。 |
| `title` | `ReactNode` | `—` | 抽屜標頭的主標題文字。 |
| `description` | `ReactNode` | `—` | 顯示於標題下方的輔助說明。 |
| `footer` | `ReactNode` | `—` | 顯示於底部的操作按鈕區域。 |
| `position` | `'right' \| 'left' \| 'top' \| 'bottom' \| 'start' \| 'end' \| 'center'` | `'right'` | 抽屜展開的視窗邊緣位置。 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | 左右展開時決定最大寬度，上下展開時決定最大高度。 |
| `isDismissable` | `boolean` | `true` | 是否允許點擊遮罩背景或手勢滑動關閉。 |
| `preventDismissal` | `boolean` | `!isDismissable` | 明確禁止透過背景點擊或滑動手勢關閉。 |
| `swipeDirection` | `'left' \| 'right' \| 'up' \| 'down' \| 'none'` | 依 `position` 自動判斷 | 覆寫滑動關閉手勢的方向。 |
| `snapPoints` | `Array<number \| string>` | `—` | 抽屜可停靠的滑動段落比例或尺寸點。 |
| `isOpen` / `defaultOpen` | `boolean` | `—` | 受控或預設的開啟狀態。 |
| `onOpenChange` | `(isOpen: boolean) => void` | `—` | 開啟或關閉狀態變化時觸發的回呼函式。 |
