## API Reference

Built on React Aria `Button` (`AriaButtonProps`) with `buttonVariants` token mappings.

### Button

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary' \| 'subtle' \| 'ghost' \| 'danger'` | `'primary'` | Visual hierarchy and semantic color role. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control height (`24px`–`40px`), padding, and label scale. |
| `isDisabled` | `boolean` | `false` | Disables press interaction and keyboard focus (alias: `disabled`). |
| `disabled` | `boolean` | `false` | HTML-style alias normalized to `isDisabled`. |
| `onPress` | `(e: PressEvent) => void` | `—` | Unified mouse, touch, and keyboard activation handler. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button behavior inside forms. |
| `className` | `string \| ((props) => string)` | `—` | Additional UnoCSS classes merged safely via `cn()`. |

Compact density scale spans `xs` (24px), `sm` (28px), `md` (32px), `lg` (36px), and `xl` (40px).
