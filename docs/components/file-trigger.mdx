```tsx
import { FileTrigger } from '@pact-design/react'

<FileTrigger
  acceptedFileTypes={['.json', '.svg', '.png']}
  onSelect={(files) => console.log(files)}
/>
```

## 何時使用

- 當介面需要讓使用者匯入設定檔、上傳圖片附件或選取本地資料夾時使用。
- 預設會直接呈現帶上傳圖示的標準按鈕；若需要套用自訂文字連結、純圖示按鈕或其他可點擊元件，也可將自訂元件作為子節點包入其中。

## 使用範例

### 樣式與尺寸

直接透過 `variant`、`size` 與 `label` 調整內建按鈕的外觀，並可搭配 `allowsMultiple` 開放一次選取多個檔案。

<ComponentPreview>
  <FileTrigger variant="primary" size="sm" label="Primary (sm)" acceptedFileTypes={['.json']} />
  <FileTrigger variant="subtle" size="md" label="Subtle (multiple)" allowsMultiple acceptedFileTypes={['image/*']} />
</ComponentPreview>

```tsx
<FileTrigger variant="primary" size="sm" label="Primary (sm)" acceptedFileTypes={['.json']} />
<FileTrigger variant="subtle" size="md" label="Subtle (multiple)" allowsMultiple acceptedFileTypes={['image/*']} />
```

### 自訂觸發元件

傳入自訂的按鈕作為子元件，即可完全掌控外觀與圖示排版。

<ComponentPreview>
  <FileTrigger acceptedFileTypes={['.svg']}>
    <Button variant="ghost" size="sm">Attach SVG</Button>
  </FileTrigger>
</ComponentPreview>

```tsx
import { Button, FileTrigger } from '@pact-design/react'

<FileTrigger acceptedFileTypes={['.svg']}>
  <Button variant="ghost" size="sm">Attach SVG</Button>
</FileTrigger>
```

## API 參考

### FileTrigger

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `label` | `ReactNode` | `'Choose file'` | 使用內建按鈕時顯示的文字內容。 |
| `variant` | `'primary' \| 'secondary' \| 'subtle' \| 'ghost' \| 'danger'` | `'secondary'` | 內建按鈕的視覺樣式。 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 內建按鈕的高度尺寸。 |
| `icon` | `ReactNode` | 預設上傳圖示 | 替換內建按鈕左側的圖示。 |
| `acceptedFileTypes` | `string[]` | `—` | 允許選擇的副檔名或 MIME 類型清單，例如 `['.json', 'image/*']`。 |
| `allowsMultiple` | `boolean` | `false` | 是否允許一次選擇多個檔案。 |
| `acceptDirectory` | `boolean` | `false` | 是否改為選擇整個資料夾。 |
| `onSelect` | `(files: FileList \| null) => void` | `—` | 使用者完成選取後觸發的回呼函式。 |
| `children` | `ReactNode` | `—` | 自訂可點擊的觸發元件，傳入後將取代內建按鈕。 |
