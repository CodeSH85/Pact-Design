## 何時使用

- 適合用來切換「立即生效」的系統偏好或功能開關，例如啟用深色模式、開啟自動儲存、允許通知推播。
- 若變更需要等使用者按下「儲存」或「送出」按鈕才會生效，或需要從多個選項中複選，建議改用 **Checkbox 核取方塊**。

## 使用範例

### 尺寸

提供緊湊 `sm` 與標準 `md` 兩種尺寸，方便搭配高密度設定列或一般表單頁面。

<ComponentPreview align="start">
  <div className="flex flex-col gap-md">
    <Switch size="sm" defaultChecked label="緊湊尺寸開關" />
    <Switch size="md" defaultChecked label="標準尺寸開關" />
  </div>
</ComponentPreview>

```tsx
<Switch size="sm" defaultChecked label="緊湊尺寸開關" />
<Switch size="md" defaultChecked label="標準尺寸開關" />
```

### 停用狀態

可同時呈現已開啟或未開啟的鎖定設定，清楚告知使用者目前狀態但不可變更。

<ComponentPreview align="start">
  <div className="flex flex-col gap-md">
    <Switch disabled label="已停用且未開啟" />
    <Switch disabled defaultChecked label="已停用且維持開啟" />
  </div>
</ComponentPreview>

```tsx
<Switch disabled label="已停用且未開啟" />
<Switch disabled defaultChecked label="已停用且維持開啟" />
```

## API 參考

### Switch

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'md'` | `'md'` | 開關軌道與滑塊的尺寸大小。 |
| `label` | `ReactNode` | `—` | 顯示於開關旁的主要文字標籤。 |
| `description` | `ReactNode` | `—` | 顯示於標籤下方的補充說明。 |
| `isSelected` / `checked` | `boolean` | `—` | 受控模式下的開啟狀態。 |
| `defaultSelected` / `defaultChecked` | `boolean` | `false` | 非受控模式下的預設開啟狀態。 |
| `onChange` / `onCheckedChange` | `(isSelected: boolean) => void` | `—` | 開關狀態切換時觸發的回呼函式。 |
| `isDisabled` / `disabled` | `boolean` | `false` | 是否停用開關互動。 |
| `className` | `string` | `—` | 額外套用的自訂樣式類別。 |
