## API Reference

Built on React Aria `Switch`. Accepts React Aria toggle props (`isSelected`, `defaultSelected`, `onChange`) alongside HTML-style aliases (`checked`, `defaultChecked`, `onCheckedChange`).

### Switch

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'md'` | `'md'` | Controls track dimensions and thumb translation distance. |
| `label` | `ReactNode` | `—` | Primary label shown next to the toggle track. |
| `description` | `ReactNode` | `—` | Secondary description caption underneath `label`. |
| `isSelected` / `checked` | `boolean` | `—` | Controlled toggle state. |
| `defaultSelected` / `defaultChecked` | `boolean` | `false` | Initial toggle state for uncontrolled switches. |
| `onChange` / `onCheckedChange` | `(isSelected: boolean) => void` | `—` | Handler called whenever the toggle state flips. |
| `isDisabled` / `disabled` | `boolean` | `false` | Disables interaction and applies muted track/thumb colors. |
| `className` | `string` | `—` | Optional CSS classes for the root switch wrapper. |
