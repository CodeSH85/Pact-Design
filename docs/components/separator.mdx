## 何時使用

- **水平區塊分隔**：用於劃分設定頁段落、側邊欄選單群組或卡片上下區域。
- **垂直項目分隔**：用於工具列或狀態列中，區隔不同性質的功能按鈕與資訊項目。

當兩段內容已經能透過留白距離清楚分組時，不需強加分隔線，避免讓畫面充滿過多線條。

## 對比層級

透過 `tone` 調整線條深淺，依區塊重要程度選擇柔和 `subtle`、標準 `default` 或強調 `strong`。

## 垂直工具列分隔

將 `orientation` 設為 `vertical`，即可在水平排列的工具列或導覽列中插入垂直分隔線。

## API 參考

### Separator

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 分隔線的排列方向，可選水平或垂直。 |
| `tone` | `'subtle' \| 'default' \| 'strong'` | `'subtle'` | 分隔線的視覺對比強度。 |
| `elementType` | `string` | 水平為 `'hr'`，垂直為 `'div'` | 底層渲染的語意 HTML 元素。 |
| `className` | `string` | `—` | 額外套用的自訂樣式類別。 |
