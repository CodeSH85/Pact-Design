## API Reference

Built on React Aria `Separator` (`AriaSeparatorProps`).

### Separator

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Sets full-width `h-px` horizontal rule or stretching `w-px` vertical divider. |
| `tone` | `'subtle' \| 'default' \| 'strong'` | `'subtle'` | Maps hairline fill to semantic `border-*` contrast tokens. |
| `elementType` | `string` | `'hr'` (horizontal) / `'div'` (vertical) | Underlying semantic DOM element managed by React Aria. |
| `className` | `string` | `—` | Additional CSS classes merged via `cn()`. |
