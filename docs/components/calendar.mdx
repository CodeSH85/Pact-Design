## API Reference

Built on React Aria `Calendar` primitives. Exports `Calendar`, `CalendarHeading`, `CalendarGrid`, `CalendarGridHeader`, `CalendarHeaderCell`, `CalendarGridBody`, and `CalendarCell`.

### Calendar

When `children` is omitted, renders the default previous/next header, `CalendarHeading`, and `CalendarGrid`.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `DateValue` | `—` | Controlled selected date (`@internationalized/date`). |
| `defaultValue` | `DateValue` | `—` | Initial selected date for uncontrolled usage. |
| `onChange` | `(value: DateValue) => void` | `—` | Callback fired when a date cell is selected. |
| `minValue` | `DateValue` | `—` | Minimum selectable date. |
| `maxValue` | `DateValue` | `—` | Maximum selectable date. |
| `isDisabled` | `boolean` | `false` | Disables navigation and date selection. |
| `isReadOnly` | `boolean` | `false` | Prevents changing the current selection. |
| `className` | `string` | `—` | Optional CSS classes for the root calendar container. |

### Parts

- **`CalendarHeading`**: Displays the current month and year heading.
- **`CalendarGrid`**: Table wrapper that defaults to rendering `CalendarGridHeader` and `CalendarGridBody`.
- **`CalendarCell`**: Individual day button styled for today, selected, outside-month, disabled, and unavailable states.

## Examples

Restrict selectable dates to a valid range with `minValue` and `maxValue`.
