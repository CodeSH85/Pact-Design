## 何時使用

- 適合需要在側邊欄、排程介面或儀表板中常駐展示完整月曆，讓使用者一覽整月日期分佈並直接點選時使用。
- 內建「今日」與「已選取」的清晰視覺標記，並支援使用方向鍵在日期格之間快速移動。
- 若只需於表單中佔用單行欄位空間，建議改用 **DatePicker 日期選擇器**。

## 使用範例

### 限定可選範圍

透過 `minValue` 與 `maxValue` 劃定有效日期區間，範圍外的日期會自動顯示為不可選取狀態。

<ComponentPreview>
  <Calendar
    aria-label="Constrained schedule"
    defaultValue={parseDate('2026-11-18')}
    minValue={parseDate('2026-11-10')}
    maxValue={parseDate('2026-11-24')}
  />
</ComponentPreview>

```tsx
<Calendar

  defaultValue={parseDate('2026-11-18')}

  maxValue={parseDate('2026-11-24')}
/>
```

## API 參考

### Calendar

省略子元件時，會自動渲染上下月切換標頭、`CalendarHeading` 與 `CalendarGrid`。

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `value` | `DateValue` | `—` | 受控模式下目前選取的日期。 |
| `defaultValue` | `DateValue` | `—` | 非受控模式下的預設選取日期。 |
| `onChange` | `(value: DateValue) => void` | `—` | 使用者點選日期格時觸發的回呼函式。 |
| `minValue` | `DateValue` | `—` | 允許選取的最早日期。 |
| `maxValue` | `DateValue` | `—` | 允許選取的最晚日期。 |
| `isDisabled` | `boolean` | `false` | 是否停用月份切換與日期點選。 |
| `isReadOnly` | `boolean` | `false` | 是否鎖定目前選取結果不允許變更。 |
| `className` | `string` | `—` | 額外套用於最外層容器的自訂樣式類別。 |

### 子元件

- **`CalendarHeading`**：顯示目前瀏覽的年份與月份標題。
- **`CalendarGrid`**：月曆表格容器，預設包含星期表頭與日期格主體。
- **`CalendarCell`**：單一日期按鈕，自動呈現今日、已選取、非當月與停用狀態。
