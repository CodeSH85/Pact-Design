## API Reference

Built on React Aria `Tabs`, `TabList`, `Tab`, `TabPanels`, and `TabPanel`. Styling context (`variant` and `size`) propagates automatically from `Tabs` down to `TabList` and `Tab`.

### Tabs

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'underline' \| 'segmented' \| 'pill'` | `'underline'` | Visual tab indicator style propagated via `TabContext`. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Controls trigger height, padding, and label typography scale. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout axis for tabs and content panels. |
| `items` | `TabItemData[]` | `—` | Data-driven alternative (`{ id, label, content, isDisabled? }`). |
| `selectedKey` / `defaultSelectedKey` | `Key` | `—` | Controlled or initial selected tab key. |
| `onSelectionChange` | `(key: Key) => void` | `—` | Callback fired when active tab changes. |
| `isDisabled` | `boolean` | `false` | Disables interaction across all tabs. |

### Parts

- **`TabList`**: Container wrapping `Tab` triggers with variant borders/tracks.
- **`Tab`**: Interactive tab trigger supporting `isDisabled`.
- **`TabPanels`** & **`TabPanel`**: Focus-safe panel region rendered for the active tab key.

### Variant

Switch seamlessly between `underline`, `segmented`, and `pill` presentations.

      <TabPanel id="preview">Segmented control variant with elevated active indicator.</TabPanel>

    <Tabs variant="pill" defaultSelectedKey="all">

### Vertical Orientation & Data Items

Set `orientation="vertical"` or pass `items` for side-tab navigation.

</ComponentPreview>
