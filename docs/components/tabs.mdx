## 何時使用

- 當同一頁面包含多組同層級、相關聯的內容檢視，讓使用者在不離開目前畫面的情況下快速切換瀏覽。
- **底線樣式 `underline`**：適合頁面主分頁或卡片上方分區，視覺輕盈且具明確層次。
- **分段樣式 `segmented`**：適合在緊湊工具區或檢視器中切換模式，例如「Preview / Code / API」。
- **膠囊樣式 `pill`**：適合用於分類篩選或局部內容切換。

若各分頁內容之間毫無關聯，或需要獨立網址與完整頁面架構，建議改用主導覽列切換頁面。

## 使用範例

### 視覺樣式

透過 `variant` 切換 `underline`、`segmented` 與 `pill` 三種樣式，設定會自動套用至所有子頁籤。

<ComponentPreview align="stretch">
  <div className="flex flex-col gap-lg">
    <Tabs variant="segmented" defaultSelectedKey="preview">
      <TabList aria-label="Segmented tabs">
        <Tab id="preview">Preview</Tab>
        <Tab id="code">Code</Tab>
        <Tab id="api">API</Tab>
      </TabList>
      <TabPanel id="preview">Segmented variant panel.</TabPanel>
      <TabPanel id="code">Source snippet panel.</TabPanel>
      <TabPanel id="api">API reference panel.</TabPanel>
    </Tabs>

    <Tabs variant="pill" defaultSelectedKey="all">
      <TabList aria-label="Pill tabs">
        <Tab id="all">All</Tab>
        <Tab id="open">Open</Tab>
        <Tab id="done">Done</Tab>
      </TabList>
      <TabPanel id="all">Pill variant panel for all items.</TabPanel>
      <TabPanel id="open">Filtered view for open items.</TabPanel>
      <TabPanel id="done">Filtered view for completed items.</TabPanel>
    </Tabs>
  </div>
</ComponentPreview>

```tsx
<Tabs variant="segmented" defaultSelectedKey="preview">
  <TabList aria-label="Segmented tabs">
    <Tab id="preview">Preview</Tab>
    <Tab id="code">Code</Tab>
  </TabList>
  <TabPanel id="preview">...</TabPanel>
  <TabPanel id="code">...</TabPanel>
</Tabs>
```

### 垂直排列與資料驅動

設定 `orientation="vertical"` 可將頁籤排列於左側作為設定頁子導覽，亦可直接傳入 `items` 陣列快速生成。

<ComponentPreview align="stretch">
  <Tabs
    orientation="vertical"
    variant="underline"
    defaultSelectedKey="general"
    items={[
      { id: 'general', label: 'General', content: 'General workspace preferences.' },
      { id: 'security', label: 'Security', content: 'Authentication and access policies.' },
      { id: 'disabled', label: 'Disabled', content: 'Unavailable section.', isDisabled: true }
    ]}
  />
</ComponentPreview>

```tsx
<Tabs
  orientation="vertical"
  defaultSelectedKey="general"
  items={[
    { id: 'general', label: 'General', content: 'General workspace preferences.' },
    { id: 'security', label: 'Security', content: 'Authentication and access policies.' },
    { id: 'disabled', label: 'Disabled', content: 'Unavailable section.', isDisabled: true }
  ]}
/>
```

## API 參考

### Tabs

| 屬性 | 型別 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'underline' \| 'segmented' \| 'pill'` | `'underline'` | 頁籤視覺樣式，會自動傳遞至內層 `TabList` 與 `Tab`。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 頁籤觸發區高度、內距與文字大小。 |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 頁籤列與內容面板的排列方向。 |
| `items` | `TabItemData[]` | `—` | 資料驅動陣列，每筆包含 `id`、`label`、`content` 與 `isDisabled`。 |
| `selectedKey` / `defaultSelectedKey` | `Key` | `—` | 受控或預設啟用的頁籤鍵值。 |
| `onSelectionChange` | `(key: Key) => void` | `—` | 切換頁籤時觸發的回呼函式。 |
| `isDisabled` | `boolean` | `false` | 一次停用所有頁籤。 |

### 子元件

- **`TabList`**：包裹多個 `Tab` 觸發按鈕的頁籤列容器。
- **`Tab`**：單一可互動的頁籤按鈕，支援個別設定 `isDisabled`。
- **`TabPanels`** 與 **`TabPanel`**：對應目前選取頁籤的內容面板區域。
